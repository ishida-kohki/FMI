電子静止系での平衡の直接導出

3成分SNR平衡を最初から電子静止系（\(\beta_e=0\)）で解く手順とその検証
——自然系で解いてから boost する2段階（frame-homotopy）を廃した直接1段階解

概要

solve_snr_equilibrium_electron_frame は、3成分SNR平衡を最初から電子静止系 （\(\beta_e=0\)）で直接解く。以前は「自然系（電流中性系）で解いてから boost で電子静止系へ運ぶ」 2段階（frame-homotopy）だったが、これを廃し、\(\beta_e=0\) の支配方程式を \(a_0\) ランプ1本で解く 直接1段階解に置き換えた。得られる \(\Phi,E_{0y}\) は電子静止系の物理場そのもので、 boost による後補正・読み替えは不要。

結論先取り: 電子静止系では入力の自然系ドリフトから \(\beta_{e,\mathrm{nat}}\) を差し引いた 電子系ドリフトを使い、\(\beta_e=0\) で残差を解く。ただし \(\beta_e=0\) では線形 seed が縮退する （§seed 縮退）ため、seed だけ自然系ドリフトで初期化して正しい basin を選ぶ。検証では \(\beta_e=6.9\times10^{-18}\)（機械精度で 0）、native 残差 \(\sim10^{-7}\)、自然系解との \(B_{0z}\)・密度一致（\(\lesssim10^{-4}\)）を確認した。
なぜ直接導出にしたか: Jikei+ 2024 は系を電子静止系で定義する （電荷中性＋純電流ゼロで \(v_{\rm ref}=(1-N)V_{sh},\ v_{\rm inc}=-N V_{sh}\)）。平衡を電子静止系で直接解けば、 boost の読み替えなしに論文と同じフレーム・同じドリフト規約で比較できる。式の対称性は自然系の方が 素直だが（\(\beta_e\) が中性条件で一意）、その利点は seed にのみ残し（下記）、平衡本体は電子系で解く。

なぜ電子静止系か

線形解析では摂動を \(\delta g \propto \exp(i k_x x - i\omega t)\) と置く。背景ドリフト \(\beta_s\) を持つ成分の応答には Doppler 因子

\[ \Omega_s \equiv \omega - k_x\,\beta_s\,c \]

が現れる。電子を静止系に取る（\(\beta_e=0\)）と電子の Doppler 因子が \(\Omega_e=\omega\) となり、電子感受率がドリフトなしの素の形に簡約される。 分散関係から電子由来の \((\omega-k_x\beta_e c)\) 依存性が消え、固有値問題が単純化する。 これが平衡を電子静止系で用意したい理由。

\(\beta_e\) は独立パラメータではなく、電流中性条件 \(\beta_e=(1-\eta)\beta_{inc}+\eta\beta_{ref}\) でドリフトから決まる （snr_equilibrium.py）。鏡面反射の規約では \(\beta_e\) は小さいが厳密には 0 でない。

フレーム変換の物理（ガリレイ・ブースト）

電子静止系へ移すのは速度 \(\beta_e\) のガリレイ・ブースト。非相対論（\(O(\beta)\)）では 場とドリフトが次のように変換する。

\[ \Phi' = \Phi - \beta_e A,\qquad A' = A,\qquad \beta_s' = \beta_s - \beta_e \]

これらから各物理量の変換を導ける:

量変換理由
密度 \(n_s\)不変 \(\Phi'-\beta_s'A' = (\Phi-\beta_e A)-(\beta_s-\beta_e)A = \Phi-\beta_s A\)。Boltzmann 因子の指数が不変
磁場 \(B_{0z}=-dA/dy\)不変 \(A\) を変えないため
電場 \(E_{0y}=-d\Phi/dy\)\(E_{0y}' = E_{0y} - \beta_e B_{0z}\) \(-d(\Phi-\beta_e A)/dy = E_{0y} + \beta_e\,dA/dy = E_{0y} - \beta_e B_{0z}\)（motional EMF）
電流 \(J_x=\sum_s q_s\beta_s n_s\)\(J_x' = J_x - \beta_e\rho\) ドリフトが \(\beta_s-\beta_e\) になる対流項。\(\rho=\sum_s q_s n_s\)

密度が不変なので \(\rho\) も不変、\(A\) も（1次では）不変で \(B_{0z}\) も不変。\(E_{0y}\) だけが motional EMF \(-\beta_e B_{0z}\) でシフトする。これが両系の解を結ぶ中心的恒等式であり、 直接解では \(E_{0y}\) がこのシフト後の電子系の値としてそのまま出る（boost 後補正は不要）。

厳密性の注: 局所電流は \(J_x'=J_x-\beta_e\rho\) と変わるため、Ampère \(d^2A/dy^2=-J_x\) から \(B_{0z}\) は厳密には \(O(\beta_e^2)\) だけ両系でずれる（相対論では \(B_z'=B_z-\beta_e E_y\)）。 直接解はこの \(J_x'\) をそのまま解くので、電子系の \(B_{0z}\) を近似なしに得る。\(\beta_e\sim7.5\times10^{-4}\) では \(O(\beta_e^2)\sim10^{-6}\) と無視できる（数値検証で \(B_{0z}\) 差 \(\lesssim10^{-4}\) は主に再解の格子・収束差）。

素朴な解き直しが失敗する理由 seed 縮退

「電子静止系のドリフトを直接 solve_snr_equilibrium に渡して解き直す」のは 失敗する。初期推定（線形分散 seed）が結合係数

\[ C_{AP} = \frac{\beta_e}{T_e} + \frac{(1-\eta)\beta_{inc}}{T_{inc}} + \frac{\eta\beta_{ref}}{T_{ref}} \]

に依存するため。\(T_{inc}=T_{ref}=T_i\) のとき、定義 \((1-\eta)\beta_{inc}+\eta\beta_{ref}=\beta_e\) を使うと

\[ C_{AP} = \frac{\beta_e}{T_e} + \frac{\beta_e}{T_i} = \beta_e\left(\frac{1}{T_e}+\frac{1}{T_i}\right) \quad\xrightarrow{\;\beta_e=0\;}\quad C_{AP}=0 . \]

\(C_{AP}=0\) だと seed の2次方程式 \(C_{AP}r^2+(C_{AA}-C_{PP})r+C_{AP}=0\) が縮退し、\(\Phi/A\) 比が \(r=0\)（純静電）へ落ちる。結果、電磁モードの種が失われ、誤った短波長 静電分枝（\(\lambda_0\to0\) の basin）へ収束してしまう。

実測: 電子系ドリフトを素で渡すと \(\lambda_0\) が崩壊（例 \(7.9\to0.03\)、native 残差 \(\sim10^{-1}\)）。 scipy.optimize.root(lm) はこの崩壊解でも success=True を返すので、native 残差の独立チェックが要る。 回避策は「seed だけ自然系ドリフトで計算する」こと——残差・抽出は \(\beta_e=0\) のまま、初期推定の \(C_{AP},C_{AA}\) を \(\beta_{e,\mathrm{nat}}\neq0\) の自然系値で作れば非ゼロの \(\Phi/A\) 比が入り、正しい basin に収束する。 これが次節の直接導出アルゴリズムの核心。

直接導出アルゴリズム 実装

solve_snr_equilibrium_electron_frame は、\(\beta_e=0\) の平衡を \(a_0\) ランプ1本で 直接解く。frame-homotopy（\(t:0\to1\) の連続化）も boost 後補正も行わない。 唯一の工夫は「seed だけ自然系ドリフトで作る」ことで seed 縮退を回避する点。

  1. 電子系ドリフトへ移す。 入力の自然系ドリフトから \(\beta_{e,\mathrm{nat}}=(1-\eta)\beta_{inc}+\eta\beta_{ref}\) を計算し、 \(\beta_{inc}'=\beta_{inc}-\beta_{e,\mathrm{nat}},\ \beta_{ref}'=\beta_{ref}-\beta_{e,\mathrm{nat}}\)。 これらは \((1-\eta)\beta_{inc}'+\eta\beta_{ref}'=0\) を満たし、solver が再導出する \(\beta_e\) も 0 になる。
  2. seed だけ自然系で作る。 線形分散 seed の \(C_{PP},C_{AP},C_{AA}\) を 自然系ドリフト \((\beta_{inc},\beta_{ref},\beta_{e,\mathrm{nat}})\) で計算（引数 _seed_drifts）。 \(\beta_{e,\mathrm{nat}}\neq0\) なので \(C_{AP}\neq0\)、非ゼロの \(\Phi/A\) 比が入り正しい basin を指す。
  3. \(\beta_e=0\) で残差を解く。 残差・境界条件・抽出は電子系ドリフト・\(\beta_e=0\) で構成し、 \(a_0\) を \(a_{0,\rm start}\to a_{0,\rm target}\) と増やす Newton 継続で1本のランプを解く。 得られる \(\Phi,E_{0y}\) は電子系の物理場そのもの。
入力: 自然系ドリフト β_inc, β_ref │ β_e,nat=(1-η)β_inc+η β_ref ▼ seed: 自然系ドリフトで C_AP,C_AA → 非ゼロ Φ/A 比（縮退回避） 残差: β_e=0, β_s'=β_s−β_e,nat │ a0 ランプ1本 (Newton 継続, root/lm) ▼ 電子静止系平衡: β_e=0 (厳密), E0y は電子系の値として直接出る
以前の frame-homotopy（自然系フル解→\(t:0\to1\) の boost 継続、引数 n_frame_steps）は廃止。 直接解は自然系・旧 homotopy と有効パラメータで機械精度一致（\(\eta=0.1\)–\(0.4\) で \(\lambda_0\) 差 \(<10^{-3}\)）し、 非相対論では単純差 \(\beta_s-\beta_e\) で平均電流中性が厳密に 0 になる（相対論補正 \(O(\beta^2)\) は丸め以下）。

不変量とフレームシフト恒等式

直接解が正しければ、自然系解 solve_snr_equilibrium との間で次が成り立つ（検証に使う）:

\[ \boxed{\;B_{0z}^{\,\mathrm{elec}} = B_{0z}^{\,\mathrm{nat}},\qquad n_s^{\,\mathrm{elec}} = n_s^{\,\mathrm{nat}},\qquad E_{0y}^{\,\mathrm{elec}} = E_{0y}^{\,\mathrm{nat}} - \beta_e\,B_{0z}\;} \]

したがって、自然系で見える物理（フィラメント構造・自己磁場・冷イオン電荷層など）は 電子静止系でも同一であり、唯一の違いは \(E_{0y}\) の motional シフト \(-\beta_e B_{0z}\)（\(\beta_e\sim7.5\times10^{-4}\) なので振幅 \(\sim10^{-4}\) と微小）。

数値検証

マッハ既定（\(M_S=154.92,\ \eta=0.2,\ V_{sh}/c=0.25,\ v_{te}/c=0.1,\ \sigma=0\)）の自然系入力

\[ \beta_{inc}=-0.050473,\quad \beta_{ref}=+0.198142,\quad \tilde T_e=10^{-2},\quad \tilde T_{inc}=\tilde T_{ref}=6.25\times10^{-4} \]

を solve_snr_equilibrium_electron_frame（直接解）に与え、\(N=128\) で解いて 自然系 solve_snr_equilibrium と比較（native = ソルバ自身の Chebyshev 微分による厳密残差）:

チェック結果判定
\(\beta_e\)（電子系直接解）\(6.9\times10^{-18}\)厳密に 0 ✓
native 収束残差 resA / resP\(1.6\times10^{-7}\) / \(1.1\times10^{-7}\)収束 ✓
\(\max|B_{0z}^{\mathrm{nat}}-B_{0z}^{\mathrm{elec}}|\)\(4.0\times10^{-5}\)不変 ✓
\(\max|n_e^{\mathrm{nat}}-n_e^{\mathrm{elec}}|\)\(1.5\times10^{-4}\)不変 ✓
恒等式残差 \(\max\big|E^{\mathrm{elec}}-(E^{\mathrm{nat}}-\beta_e B_{0z})\big|\)\(2.7\times10^{-5}\)成立 ✓
直接解 vs 自然系/旧 homotopy の \(\lambda_0\)（\(\eta=0.1\)–\(0.4\)）差 \(<10^{-3}\)一致 ✓
\(\beta_e\) が厳密に 0、native 残差が \(\sim10^{-7}\) で直接解が方程式を満たして収束し、 \(B_{0z}\)・密度が自然系と一致、フレームシフト恒等式 \(E^{\mathrm{elec}}=E^{\mathrm{nat}}-\beta_e B_{0z}\) が \(2.7\times10^{-5}\) で成立する。よって電子静止系での直接導出は正しく動作している。 冷イオン由来の鋭い \(E_{0y}\) 層は自然系でも同一に現れる（\(B_{0z}\)・密度がフレーム不変）ため、 フレーム選択の産物ではなく背景パラメータ（冷たいイオン）由来である。

API / コード参照

from fmi.mach_parameters import MachConfig, build_solver_params
from fmi.snr_equilibrium import (
    solve_snr_equilibrium,                 # 自然系（β_e≠0）
    solve_snr_equilibrium_electron_frame,  # 電子静止系（β_e=0, 直接解）
)

sp = build_solver_params(MachConfig(M_S=154.92, beta_sh=0.25,
                                  beta_te=0.1, sigma=0.0, eta=0.2))
# sp = {eta, beta_inc, beta_ref, Te, Tinc, Tref}（自然系ドリフト）

eq_nat  = solve_snr_equilibrium(**sp, a0_target=0.25, N_points=128)
eq_elec = solve_snr_equilibrium_electron_frame(**sp, a0_target=0.25, N_points=128)
# eq_elec["beta_e"] ≈ 0,  B0z・密度は eq_nat と一致,  E0y は −β_e·B0z だけシフト
