異方性温度 Txx をどの式に入れるか

SNR 周期電流フィラメント平衡の線形解析 — 圧力テンソルの対角成分を区別する場合の 定式化・入る箇所・平衡への影響・検証方法。2026-08-21 作成。

結論

Txx は運動量方程式の x 成分の圧力勾配項にだけ入る。 その項が圧力テンソルの xx 成分を x で微分したものだからである。

平衡には一切入らない。平衡は y にしか依存せず \(\partial_x p_{s,xx}=0\) が恒等的に成り立つため、Txx は 0 次の方程式に現れない。 したがって既存の平衡解も a0 の校正もそのまま使える。

kx=0 の結果は厳密に不変。この項は kx に比例するので、 FMI（kx=0）の成長率は Txx をどう変えても変わらない。 変わるのは斜め枝・DKI など kx≠0 のモードだけである。

いま使っている閉包

現在の実装は等方 1 温度の断熱流体閉包である。粒子種 s ごとに スカラー \(T_s\) を 1 個だけ持ち、圧力は \(p_{s}=n_{s}T_{s}\)、摂動圧力は \(\delta p_s=\gamma_{\rm ad}T_s\,\delta n_s\)（\(\gamma_{\rm ad}=5/3\)）とする。

この 1 個のスカラーが、運動量方程式の x 成分と y 成分の両方で使われている。

\[ \text{運動 } x:\quad m_s n_{s0}(-i\Omega_s)\,\delta v_{sx} \;=\; q_s n_{s0}\delta E_x + q_s n_{s0}B_{0z}\delta v_{sy} \;\underbrace{-\,i k_x\,\gamma_{\rm ad}T_s\,\delta n_s}_{\text{圧力}} \]
\[ \text{運動 } y:\quad m_s n_{s0}(-i\Omega_s)\,\delta v_{sy} \;=\; q_s n_{s0}\delta E_y - q_s n_{s0}\big(B_{0z}\delta v_{sx}+u_{s0x}\delta B_z\big) + q_s\delta n_s\big(E_{0y}-\beta_sB_{0z}\big) \;\underbrace{-\,\partial_y\big(\gamma_{\rm ad}T_s\,\delta n_s\big)}_{\text{圧力}} \]

コード上では BackgroundProfiles.T が dict[str, float]、 すなわち粒子種名からスカラー 1 個への写像になっている （src/fmi/snr_linear.py:41）。

CGL とは何か

CGL は Chew–Goldberger–Low の頭文字、すなわち 1956 年の論文の 著者 3 名の名前である （Proc. R. Soc. Lond. A 236, 112, 1956）。 無衝突磁化プラズマにおける異方性圧力の流体閉包を指し、 double-adiabatic（二重断熱）理論とも呼ばれる。 異方性プラズマの流体記述としては最も標準的な枠組みである。

解こうとしている問題

衝突があるプラズマでは、衝突が速度分布を等方化するので圧力はスカラー 1 個で足りる。 無衝突プラズマではこれが成り立たず、圧力は 2 階のテンソル \(\mathsf{P}_{ij}=m\!\int (v_i-u_i)(v_j-u_j)\,f\,d^3v\) になる。 独立成分は 6 個あり、そのままでは流体方程式が閉じない。

CGL はこれを磁場の存在を使って 2 成分に減らす。

鍵はジャイロ運動による対称化

磁場中の荷電粒子は磁力線のまわりを角振動数 \(\Omega_c=qB/mc\) で旋回する。 着目する現象の時間スケールがこの旋回より遅ければ （\(\omega \ll \Omega_c\)、かつ空間スケールがラーマー半径より大きければ）、 分布関数は磁力線方向を軸として回転対称になるまで均される。 この性質をジャイロトロピックという。

B の向き（磁力線） | | 粒子はこの軸のまわりを高速で旋回する \ | / \ | / → 軸に垂直な面内では方向の区別がなくなる \ | / すなわち p_xx = p_yy = p_perp --------------- / | \ / | \ → 軸に平行な方向だけが別扱い / | \ すなわち p_zz = p_para | |

ジャイロトロピックなら、圧力テンソルの独立成分は 2 個だけになる。

\[ \mathsf{P} \;=\; p_\parallel\,\hat{b}\hat{b} \;+\; p_\perp\big(\mathsf{I}-\hat{b}\hat{b}\big), \qquad \hat{b}\equiv\mathbf{B}/|\mathbf{B}| \]
記号意味
\(\hat{b}\)磁力線方向の単位ベクトル
\(p_\parallel\)磁力線に平行方向の圧力
\(p_\perp\)磁力線に垂直な面内の圧力。この面内では等方

なぜ「二重断熱」なのか

等方の断熱則は \(p/n^{5/3}=\) 一定 の 1 本だけである。 CGL では \(p_\parallel\) と \(p_\perp\) の 2 つを決める必要があり、 2 本の保存則を使う。どちらも粒子運動の断熱不変量から来る。

\[ \frac{d}{dt}\!\left(\frac{p_\perp}{n B}\right)=0 \qquad\Longleftarrow\qquad \text{磁気モーメント } \mu=\frac{m v_\perp^2}{2B} \text{ の保存} \]
\[ \frac{d}{dt}\!\left(\frac{p_\parallel B^2}{n^3}\right)=0 \qquad\Longleftarrow\qquad \text{縦方向（磁力線に沿う往復運動）の断熱不変量} \]

断熱則が 2 本あるので「二重断熱」と呼ばれる。 物理的な中身は「磁場が強まると垂直方向の運動エネルギーが増え （\(p_\perp\propto nB\)）、磁力線が伸びると平行方向が圧縮される （\(p_\parallel\propto n^3/B^2\)）」である。

成り立つための仮定

仮定内容破れると
無衝突衝突が異方性を均さない等方に戻り通常の流体になる
ジャイロ運動が速い\(\omega\ll\Omega_c\)、\(kr_L\ll1\)ジャイロトロピックでなくなる
熱流ゼロ磁力線に沿う熱の輸送を無視Landau 減衰などが入り閉じない
磁場が有限\(\hat{b}\) が定義できる異方性の軸自体が決まらない

CGL の異方性は「磁場に対する平行 / 垂直」でしか表現できない。 これが本研究で使えない直接の理由になる（次節）。

CGL から出る代表的な不安定性背景知識

CGL の異方性は、それ自体が不安定性の自由エネルギー源になる。 磁気圏物理や太陽風の研究で標準的に使われるのはこのためである。

  • ファイアホース不安定性（\(p_\parallel > p_\perp\)）— 磁力線に沿う圧力が磁気張力に打ち勝ち、磁力線が横にたわむ。 消防ホースが暴れる様子から名前が付いている。
  • ミラー不安定性（\(p_\perp > p_\parallel\)）— 磁場が弱い場所に粒子が溜まり、磁場をさらに押しのける。

本研究の異方性は \(T_{yy}\gg T_{xx}\) であり、これらのどちらの分類にも そのままでは当てはまらない。異方性の軸が磁場方向ではないためである。

CGL では扱えない理由

異方性プラズマの標準的な閉包は CGL（double-adiabatic）だが、ここでは使えない。

CGL は磁力線方向を軸とするジャイロトロピック異方性 \(\mathsf{P}=p_\parallel\hat{b}\hat{b}+p_\perp(\mathsf{I}-\hat{b}\hat{b})\) を仮定する。 本系の背景磁場は面外成分のみ \(\mathbf{B}_0=B_{0z}(y)\hat{z}\) なので、 ジャイロトロピックなら \(\hat{b}=\hat{z}\) となり

\[ p_\parallel = p_{zz},\qquad p_\perp = p_{xx}=p_{yy} \]

すなわち CGL は Txx=Tyy を予言する。 しかし実測は Tyy/Txx = 8.43 である。予言と実測が真っ向から矛盾する。

物理的な理由は明確である。異方性を作っているのは磁場ではなく、 2 つの独立した特別な方向である。

  • x = ビーム方向。相対ドリフト 2vsh≈0.25c が自由エネルギー源。
  • y = Weibel 変調方向。フィラメントが並ぶ方向で、粒子はここで磁場に跳ね返されて加熱される。
  • z = 面外方向。自由エネルギーも変調もないので加熱されない（実測 Tzz は初期値のまま）。

ジャイロ運動が異方性を均す前に Weibel が加熱するため、分布は非ジャイロトロピックになる。 したがって必要なのは CGL ではなく、実験室系 (x,y,z) の対角圧力テンソルである。

圧力テンソルからの導出

出発点は圧力テンソルを持つ運動量方程式。

\[ m_s n_s\Big[\partial_t + (\mathbf{v}_s\cdot\nabla)\Big]\mathbf{v}_s \;=\; q_s n_s\big(\mathbf{E}+\mathbf{v}_s\times\mathbf{B}\big) \;-\; \nabla\cdot\mathsf{P}_s \]

非対角成分をゼロと仮定し（後述の限界を参照）、対角テンソルを取る。

\[ \mathsf{P}_s = \mathrm{diag}\big(p_{s,xx},\,p_{s,yy},\,p_{s,zz}\big), \qquad p_{s,ii}=n_s T_{s,ii} \]

本系は z 方向に一様（\(\partial_z=0\)）なので、発散の各成分は 1 項ずつしか残らない。 ここが決定的な点である。

\[ (\nabla\cdot\mathsf{P}_s)_x = \partial_x p_{s,xx} + \underbrace{\partial_y p_{s,yx}}_{=0} + \underbrace{\partial_z p_{s,zx}}_{=0} = \partial_x p_{s,xx} \]
\[ (\nabla\cdot\mathsf{P}_s)_y = \underbrace{\partial_x p_{s,xy}}_{=0} + \partial_y p_{s,yy} + \underbrace{\partial_z p_{s,zy}}_{=0} = \partial_y p_{s,yy} \]

x 成分には xx 成分しか、y 成分には yy 成分しか現れない。 対角テンソルかつ z 一様であれば、両者は完全に分離する。 したがって「Txx をどこに入れるか」に曖昧さはない。

摂動を \(\delta g \propto \exp(ik_xx-i\omega t)\) と置き、断熱閉包を各軸に適用すると

\[ \delta p_{s,xx}=\gamma_x T_{s,xx}\,\delta n_s,\qquad \delta p_{s,yy}=\gamma_y T_{s,yy}\,\delta n_s \]

圧力勾配の力は

\[ -(\nabla\cdot\delta\mathsf{P}_s)_x = -\,i k_x\,\gamma_x T_{s,xx}\,\delta n_s, \qquad -(\nabla\cdot\delta\mathsf{P}_s)_y = -\,\partial_y\big(\gamma_y T_{s,yy}\,\delta n_s\big) \]

相対密度版で dlogn0 が付いている理由補足

相対密度変数 \(w_s=\delta n_s/n_{s0}\) では \(\delta n_s=n_{s0}w_s\) なので、 y 圧力項の \(\partial_y(\delta n_s)/n_{s0}\) が \((\partial_y+\partial_y\ln n_{s0})w_s\) になる。 dlogn0 は圧力項自身から出てくる項であり、背景場力項ではない。 よってここに掛かる温度も Tyy のままでよい。

平衡は変わらない

Txx は 0 次の方程式に一切現れない。 平衡解も a0 の校正もやり直す必要がない。

平衡は y のみに依存する（\(\partial_x=\partial_z=0\)）。したがって x 方向の力の釣り合いは

\[ 0 \;=\; q_s n_{s0}\big(E_{0x}+\dots\big) - \partial_x p_{s,xx,0} \;=\; -\,\underbrace{\partial_x p_{s,xx,0}}_{\equiv\,0} \]

となり、Txx を含む項が恒等的に消える。x 方向には平衡の勾配が存在しないので、 Txx がいくつであろうと平衡は同じである。

一方 y 方向の釣り合いは残り、これが Boltzmann 閉包を決めている。

\[ q_s n_{s0}\big(E_{0y}-\beta_s B_{0z}\big) \;=\; \partial_y p_{s,yy,0} \;=\; T_{s,yy}\,\partial_y n_{s0} \quad\Longleftrightarrow\quad n_{s0}\propto\exp\!\Big[\!-\frac{q_s(\Phi-\beta_s A)}{T_{s,yy}}\Big] \]

これが「Tyy を選ぶ」根拠である。 平衡の密度コントラスト（したがって nref,min、正則化の要否、a0 の校正値）を 決めるのは y 方向の力の釣り合いだけであり、そこに入る温度は y 成分である。 等方平均 \(T_{\rm iso}\) を使う根拠は存在しない。

背景場力項は Tyy のまま

運動 y には、密度揺らぎ \(\delta n_s\) が背景場から受ける 1 次の力 \(q_s\delta n_s(E_{0y}-\beta_sB_{0z})\) が入っている （2026-07 に追加。並進ゼロモード検査で較正済み）。

この項は上の平衡の力釣り合いを使うと

\[ q_s\,\delta n_s\big(E_{0y}-\beta_sB_{0z}\big) \;=\; T_{s,yy}\,\delta n_s\,\partial_y\ln n_{s0} \]

と書ける。y 成分の温度しか現れないので、異方性を入れても変更は不要である。 コード上でも実際の場の値 (E0y - v0 * bg.B0z) を使っており、T を明示的に参照していない。

予想される向き

圧力は圧縮に抗するので、x 方向の圧力項は kx≠0 のモードを安定化する。 Txx < Tyy なのでこの安定化は現在より弱くなる。 したがって

現在の斜め枝・DKI の成長率は過小評価されている可能性がある。 これはステップ1（波数ベクトルの kx 方向への拡張）の結論に直接効く。

ただし大きさは自明でない

x 方向の圧力応答を支配するのは音速が最大の電子であり （0.1555 対 イオン 0.0058、27 倍）、その電子の異方性は 1.11 にすぎず補正は 5% である。 反射イオンでは 66% 減と大きいが、絶対値が小さい。

どちらが効くかはモードの性質（電子的か、イオン的か）に依存するため、 正味の効果は議論ではなく測定で決めるべきである。

未解決: 断熱指数をどう取るか

現在は \(\gamma_{\rm ad}=5/3\) を両方向に使っている。これは 3 自由度が等分配され、 圧縮でエネルギーが 3 方向に自由に配分される場合の値である。

実測は方向間のエネルギー交換が弱いことを示している （Weibel 加熱が y に集中し、z が初期値のまま）。交換が完全にないなら、 各軸は独立に 1 次元断熱圧縮に従い

\[ p_{ii}\propto n^{3}\quad\Longrightarrow\quad \delta p_{ii}=3\,T_{ii}\,\delta n \qquad(\gamma=3) \]

となる。5/3 と 3 では 1.8 倍の差があり、これは電子の異方性補正（5%）より大きい。

異方性温度と断熱指数は別々の決定である。 Txx/Tyy の区別を入れると、\(\gamma_{\rm ad}\) の妥当性を 同時に問い直すことになる。両方を一度に変えると、どちらの効果を見ているか分からなくなる。 先に温度だけを変え、\(\gamma_{\rm ad}=5/3\) は固定したまま測るべきである。

def _split_temperature(T: float | tuple[float, float]) -> tuple[float, float]:
    """温度入力を (T_xx, T_yy) に正規化する。

    スカラーは等方 T_xx = T_yy = T と解釈する（従来の挙動と厳密に一致）。
    """
    if isinstance(T, (int, float)):
        return float(T), float(T)
    Txx, Tyy = T
    return float(Txx), float(Tyy)

WI_SATURATED_TX = {"Te": 1.3033e-02, "Tinc": 6.9849e-04, "Tref": 9.4597e-04}

平衡ソルバーは触らない。 solve_snr_equilibrium_electron_frame(**WI_SATURATED_TY, ...) は そのままでよい。異方性は線形演算子にだけ入る。

検証

実装が正しいことを確かめる検査を、強い順に並べる。

1. kx=0 での厳密不変性 最強

x 圧力項は kx に比例するので、kx=0 では Txx をどう変えても 固有値が 1 ビットも変わってはならない。 

# T_xx を 100 倍しても k_x=0 の結果は不変であること
L1 = build_operator_bloch(bg_iso,  kx=0.0, K=K)
L2 = build_operator_bloch(bg_aniso, kx=0.0, K=K)   # T_xx だけ 100 倍
assert np.abs(L1 - L2).max() == 0.0

これが破れたら、Txx を入れる場所を間違えている。

2. 等方入力での後方互換

スカラー T を渡したときの演算子が、変更前とビット単位で一致すること。 既存の全結果（warm natural を含む）が無効化されないことの保証になる。

3. 並進ゼロモード検査

平衡の y 微小並進は kx=0, ω=0 の厳密解であり、演算子はこれを消す （tests/test_snr_linear.py::test_translation_zero_mode_annihilated）。 この検査は kx=0 なので、検査 1 より Txx に依存せず通り続けるはずである。

4. 一様背景の cold filamentation 較正

既存の解析分散との一致検査は ky 方向のみ（kx=0）なので、 これも Txx の影響を受けない。

5. 本番の測定

検査 1–4 を通したうえで、kx 分散関係を等方版と異方性版で引き比べる。 差が出るのは kx≠0 のみで、kx=0 で 2 曲線が交わるはずである。 交わらなければ実装が誤っている。

限界

限界内容
非対角成分が未検証 PIC が出力するのは対角成分 \(P_{xx},P_{yy},P_{zz}\) のみ （um[...,s,5..7]）。異方性プラズマでは \(P_{xy}\) が有限になり得るが、 現在のデータでは確かめられない。対角と仮定して進めることになる。
断熱指数が未決 \(\gamma_{\rm ad}=5/3\) を流用する。方向間のエネルギー交換が弱い実態からは \(\gamma=3\) が示唆されるが、これは別の決定として分離する（§断熱指数）。
異方性の時間発展 Txx, Tyy は ωpit=70 の 1 点の値を定数として使う。 準定常窓（ωpit 65.5–80.0）の中で異方性比が変化するかは未確認。
空間依存を無視 温度は空間平均値であり y 依存を持たせていない。フィラメント内外で異方性が 異なる可能性があるが、Boltzmann 閉包は T が y 一定であることを要求する。
参照データが旧ラン 温度は data_sigma0_m400（Nx=8, Ny=512、実質 1D）の実測値。 x 方向の構造を分解できていない。新しい 4096×4096 の σ=0 ランで測り直す価値がある。
