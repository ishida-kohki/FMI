準定常平衡の kx 分散関係とモード同定

絶対密度版で引き直した K=0 分散関係、および固有関数と対照実験によるモードの正体判定。 研究方針〈目標に向けてのステップ 1: 波数ベクトルの拡張〉に対応。2026-08-27 作成。

結論

1. 成長モードは 2 系統あり、成長率がほぼ同等である。

  • DKI（ky=6k0, kx/k0=0.25–0.35, γ=2.23e-03）— 反射ビーム駆動、界面局在、イオン 2 種が逆相。
  • 電流駆動モード（ky=0, kx/k0=0.4–0.9, γ=2.73e-03）— 反射イオンが一切関与しない。電子–入射イオンの相対ドリフト、 背景磁場、密度勾配の 3 つが必須。

差は 20% しかなく、どちらが「支配的」かを断定できる差ではない。

2. FMI（kx=0）は成長モードが 1 つも無い。 準定常温度では熱的に安定化されている。以前の一様背景 filamentation 検査で 「反射イオンの Tyy が Weibel 臨界の 1.05 倍」と分かっていたことと整合する。

3. PIC との 3 倍の差は、平衡の密度勾配で説明できる可能性がある。 対照実験で密度勾配を消すと DKI が 3.4 倍に跳ね上がり γ=7.47e-03 となり、 PIC 実測帯 6.6–9.0e-03 のほぼ中央に入る。 検証可能な仮説として §PIC との差に示す。

なぜ引き直したか

従来の準定常平衡の分散関係（scan_snr_quasisteady_k0.py, dispersion_snr_quasisteady_ppp300.py）は相対密度版の演算子 build_operator_bloch_relative を使っていた。この演算子は急峻な密度勾配に対し D @ log(n0) の Gibbs 現象で格子カットオフに偽の成長モードを上乗せし、 最速モードだけを見るとその偽モードを掴む。

本稿はすべて絶対密度版 build_operator_bloch で計算し直したものである。 経緯の詳細は docs/linear_operator_density_variables.html。

モード選別の基準

選別は格子解像度ではなく物理で決める。断熱流体閉包には Landau 減衰が 無いので、\(k\lambda_{De}>1\) のモードは数値的に収束していても成長率として意味を持たない。

\[ \lambda_{De}=\frac{v_{te}}{\omega_{pe}}=\sqrt{T_e}=0.1204\ c/\omega_{pe}, \qquad k_y\lambda_{De}\leq1 \iff n\leq 8.77 \]

以前使っていた「卓越調波が Nyquist の 1/4 未満」という閾値は恣意的で根拠がなかった。 図では選別前（灰）と選別後（青）の 2 本を並べ、どこまでが信用できるかを判別できるようにしてある。

固有関数の形

ky=0 枝（kx/k0=0.75）

  • δne ≈ δninc が領域全体で成立。局在していない。
  • δBz が直流オフセットを持つ — これが ky=0 の実体で、 面外磁束の平均値が変化するモードである。
  • δnref は nref,0 が大きい端でだけ立つが、振幅比は 0.00。

ky=6 枝（kx/k0=0.30）

  • 界面局在モード。イオン 2 種が入れ替わる遷移層に張り付いている。
  • δnref が最大振幅で、3 種すべてが参加。
  • 平坦部（y/λ0=0.3–0.7）ではほぼ静か。
  • cos(inc,ref)=−0.67 — 入射イオンと反射イオンが界面で押し合う。

界面局在・イオン 2 種が逆相・反射ビーム駆動・電子−イオン電流に非依存。 これらから DKI（ion-ion kink 系）と同定する。 ただし静電的（|δB|²/|δE|²=0.089）である点が通常の DKI と異なる。

必要なのは「電流」「磁場」「密度勾配」の 3 つで、反射ビームは不要。 電流が作った B0z の中で、密度勾配を持つプラズマが電子−イオン相対ドリフトによって 不安定化する構造である。

これは SNR フット特有のモードではない。 電流フィラメントさえあれば成立する。研究方針の「やれそうなこと（パラメータ依存を調べる）」 の対象としては自然だが、「SNR と同じパラメータでどのモードが支配的か」への答えとしては 予想（DKI や FMI）から外れる。

FMI が消えている

kx=0 で成長モードが 1 つも無い。FMI（フィラメント併合）は 準定常温度では完全に安定化されている。

これは以前の一様背景 filamentation 検査と整合する。そこでは PIC 準定常温度で ky をどう変えても Weibel が安定（max Im ω ≤ 1e-10）であり、 反射イオンの臨界温度 7.571e-03 に対し実測 7.979e-03 — 臨界のちょうど 1.05 倍だった。教科書的な不安定性の飽和である。

仮説: 平衡ソルバーの Boltzmann 閉包が作る密度コントラスト （nmax/nmin=678）が PIC の実際の状態より急峻すぎ、 DKI を過剰に安定化しているのではないか。

検証方法: a0 を下げて密度コントラストを緩めたとき、 γ が PIC 帯に近づくかを見る。ただし a0 は PIC の Bz ピークに 合わせた量なので、下げると別の整合性を失う。トレードオフの評価が要る。

限界

限界内容
K=0 に固定 Bloch 位相 K を 0 に固定している。ky は K + n·k0 で 折り返されるので、K≠0 の枝は本稿に含まれない。ステップ 1 の残り。
x 圧力項の温度 運動量方程式 x 成分の圧力項に Tyy を使っている。本来は Txx。 反射イオンで Tyy/Txx=8.43 なので x 方向の圧力を過大評価しており、 kx≠0 のモードを過剰に安定化している可能性がある。 詳細は docs/anisotropic_pressure_closure.html。
断熱指数 γad=5/3 を両方向に使用。方向間のエネルギー交換が弱い実態からは γ=3 が示唆される（1.8 倍の差）。未検討。
「電流駆動モード」の同定が暫定 駆動源（電流・磁場・密度勾配が必須、反射ビーム不要）は確定したが、 文献上のどの不安定性に対応するかは未照合。 ドリフト波系か、電流シート内部の tearing 系かの判別が要る。
参照 PIC が旧ラン 温度は data_sigma0_m400（Nx=8, Ny=512、実質 1D） の実測値。新しい 4096×4096 の σ=0 ラン（ジョブ 8404433 完了済み）で 測り直す価値がある。

次にやること

  1. 密度勾配仮説の検証 — a0 を振って 密度コントラストと γ の関係を調べ、PIC 帯に届く条件を探す。
  2. 「電流駆動モード」の文献照合 — ky=0・電磁的・電流と密度勾配が必須という特徴に合う既知の不安定性を探す。
  3. K≠0 への拡張 — ステップ 1 の残り。 K=0 は ky が k0 の整数倍の場合しか見ていない。
  4. x 圧力項に Txx を入れる — kx≠0 の結果に直接効く。検証は kx=0 での厳密不変性で行える。
