3成分SNRプラズマ電流フィラメント平衡ソルバー

Vanthieghem et al. (2018) のChebysehvスペクトル法 + Newton継続法を
非相対論的な背景電子・入射イオン・反射イオン系に拡張した実装の解説

概要

超新星残骸（SNR）の衝撃波前面付近では、入射イオン（shock-heated ions）と 反射イオン（reflected ions）が共存した3成分プラズマが形成される。 このソルバーは、その環境で自発的に発生する電流フィラメントの 非線形平衡解（周期的定常解）をChebyshevスペクトル法とNewton継続法で求める。

基本文献: Vanthieghem, A. et al. (2018), Phys. Plasmas 25, 072115 — 相対論的ペアプラズマ平衡のChebysehvスペクトル法による解法。 本実装はこのアルゴリズムを非相対論的3成分系に拡張したもの。

3成分プラズマ系

成分電荷平均数密度ドリフト速度温度
背景電子 (e)\(-e\)\(\bar{n}_e\)（正規化基準 = 1） \(\beta_e c\)\(T_e\)
入射イオン (inc)\(+e\)\((1-\eta)\bar{n}_e\) \(\beta_{inc} c\)\(T_{inc}\)
反射イオン (ref)\(+e\)\(\eta\bar{n}_e\) \(\beta_{ref} c\)\(T_{ref}\)

\(\eta \in (0, 1)\) は反射イオンの割合（反射イオン密度比）。 \(\eta = 0\) の極限はペアプラズマ系に近似的に帰着するが、 \(\sinh\) 簡略化は使えない（後述）。

正規化単位

物理量正規化スケール記号
長さ電子プラズマ周波数の慣性長\(c/\omega_{pe}\)
速度光速 \(c\)（\(c=1\)） \(\beta_s \equiv v_s / c\)（ドリフト・熱速度とも \(/c\) の無次元量）
スカラーポテンシャル\(m_e c^2 / e\)\(\Phi \equiv e\phi_0 / m_e c^2\)
ベクトルポテンシャル\(m_e c^2 / e\)\(A \equiv eA_{0x} / m_e c^2\)
温度\(m_e c^2 / k_B\)\(T_s \equiv k_B T_s^{\rm phys} / m_e c^2\)
速度記法（統一規約）: すべての速度は \(c\) で正規化し、記号 \(\beta_{\langle 名\rangle}\) で表す（\(\beta \equiv v/c\)）。ドリフト \(\beta_e,\beta_{inc},\beta_{ref}\)、熱速度 \(\beta_{th,s}=v_{th,s}/c\)、音速 \(\beta_{cs,s}=c_s/c\)、衝撃波 \(\beta_{sh}=V_{sh}/c\) はすべて同じ規約。 熱速度と温度は \(T_s = m_s\,\beta_{th,s}^2\)（\(m_e=1\)）で結ばれる。 別物の注意: 「プラズマ \(\beta\)」（圧力比 \(2 n k_B T/(B^2/2\mu_0)\)）は速度比ではない。 混同を避けるためコードでは圧力比のみ beta_e_plasma と綴る。
注意: 質量比 \(m_i/m_e\) はこの平衡方程式には陽に現れない。 物理的なイオン慣性スケール \(c/\omega_{pi} = c/\omega_{pe} \times \sqrt{m_i/m_e}\) への変換は Floquet / 不安定性解析の段階で必要となる。

密度分布（Boltzmann分布）

各成分が局所的な熱平衡にあると仮定すると、電磁ポテンシャル \((\Phi, A)\) に対して Boltzmann分布が成立する。 非相対論的極限（\(v_{\rm drift} \ll c\））での1粒子エネルギーを使うと、 各密度は指数Boltzmann因子に比例する。 ただし比例係数は化学ポテンシャル正規化定数であり、 指数因子の空間平均が背景密度に一致するように決める：

\[ \frac{n_e}{\bar{n}_e} = \frac{\exp\!\left[(\Phi - \beta_e A)/T_e\right]} {\big\langle \exp\!\left[(\Phi - \beta_e A)/T_e\right]\big\rangle} \] \[ \frac{n_{inc}}{\bar{n}_e} = (1-\eta)\, \frac{\exp\!\left[-(\Phi - \beta_{inc} A)/T_{inc}\right]} {\big\langle \exp\!\left[-(\Phi - \beta_{inc} A)/T_{inc}\right]\big\rangle} \] \[ \frac{n_{ref}}{\bar{n}_e} = \eta\, \frac{\exp\!\left[-(\Phi - \beta_{ref} A)/T_{ref}\right]} {\big\langle \exp\!\left[-(\Phi - \beta_{ref} A)/T_{ref}\right]\big\rangle} \]

ここで \(\langle f \rangle = \frac{1}{L_{1/2}}\int_0^{L_{1/2}} f\, d\tilde{y}\) は1周期にわたる空間平均（密度は偶関数なので半周期平均と等しい）。 この正規化により定義上 \(\langle n_e\rangle = \bar{n}_e\), \(\langle n_{inc}\rangle = (1-\eta)\bar{n}_e\), \(\langle n_{ref}\rangle = \eta\bar{n}_e\) が厳密に成立する。

なぜ正規化が必須か（周期境界条件との整合）: 支配方程式を1周期積分すると、両端で \(\partial_y\Phi = \partial_y A = 0\) （Neumann境界条件）のため左辺が消え、次の積分中性条件が要求される：
\[ \int_0^{L_{1/2}} (n_e - n_{inc} - n_{ref})\, d\tilde{y} = 0, \qquad \int_0^{L_{1/2}} (\beta_e n_e - \beta_{inc} n_{inc} - \beta_{ref} n_{ref})\, d\tilde{y} = 0 \]
すなわちプロファイル平均での電荷中性・電流中性。 比例係数を背景値 \((1, 1-\eta, \eta)\) に固定すると \(\langle\exp[\cdots]\rangle \neq 1\) のためこの2条件が破れ、 厳密な平衡解が存在しなくなる。 ソルバーは最小二乗で妥協し、Neumann境界条件が破れて 折り返し点（\(y=0,\,L_{1/2}\)）に不連続なキンクが現れる。 上記の空間平均正規化を施すと、\(\langle n_e\rangle = \langle n_{inc}\rangle + \langle n_{ref}\rangle\) と \(\beta_e\langle n_e\rangle = \beta_{inc}\langle n_{inc}\rangle + \beta_{ref}\langle n_{ref}\rangle\) （後者は電流中性条件 \(\beta_e = (1-\eta)\beta_{inc} + \eta\beta_{ref}\) そのもの）が 自動的に満たされ、2条件が解消されて残差は機械精度（\(\sim 10^{-10}\)）まで収束する。

空間平均は Gauss-Lobatto ノード上の Clenshaw-Curtis 求積重み \(w_k\) を用い、 \(\langle f \rangle = \sum_k w_k f_k / \sum_k w_k\) で評価する。 離散化と同一グリッド上で平均を取るため、整合性は機械精度で保たれる。

ペアプラズマとの違い: 2成分ペアプラズマでは電子・陽電子の指数関数の差が \(\sinh\) にまとまり、 支配方程式が \(\sinh\) 型の非線形ODE（Liouville方程式）に帰着する。 この対称性により積分中性条件は自動的に満たされ、明示的な正規化は不要。 3成分系ではこの対称性が無いため、上記の化学ポテンシャル正規化が本質的に必要となる。

支配方程式

\(y\)方向の空間変化のみを考える1次元平衡では、 Maxwell方程式から正規化後の以下の2本のODEが得られる：

Poisson方程式（ガウス則）

\[ \frac{d^2\Phi}{dy^2} = n_e - n_{inc} - n_{ref} \]

Ampere方程式

\[ \frac{d^2 A}{dy^2} = \beta_e n_e - \beta_{inc}\, n_{inc} - \beta_{ref}\, n_{ref} \]

右辺は非線形であり、\(\Phi\) と \(A\) に指数関数的に依存する。 これら2本の連成2階ODE（未知関数2個、未知パラメータ \(L_{1/2}\) 1個）を Chebyshevスペクトル法で離散化してNewtonで解く。

中性条件

電荷中性（自動的に満足）

平均数密度を \(\bar{n}_{inc} = (1-\eta)\bar{n}_e\)、 \(\bar{n}_{ref} = \eta\bar{n}_e\) と定義したことにより、 一様な背景状態では \(\bar{n}_e = \bar{n}_{inc} + \bar{n}_{ref}\) が \(\eta\) の定義から自動的に成立する。 追加の方程式は不要。

電流中性（導出式）

\(x\)方向の全電流が0という条件から \(\beta_e\) を導出する：

\[ \beta_e = (1-\eta)\beta_{inc} + \eta\beta_{ref} \]

これは入力パラメータから解析的に求まるため、Newton方程式の未知数には含めない。 実装では1行の計算で処理する： 

# src/fmi/snr_equilibrium.py
beta_e = (1.0 - eta) * beta_inc + eta * beta_ref

境界条件

解の対称性から 半周期ドメイン \(\tilde{y} \in [0, L_{1/2}]\) のみを解く。 周期長 \(L_{1/2}\)（= 半周期）は未知数（固有値）として Newton 系に含める。

y = 0 y = L_half (= L/2) y = 2*L_half (= L) │ 反射イオン中心 │ 入射イオン中心(逆電流) │ 反射イオン中心(y=0と同種) │ │ │ A(0) = a₀ (振幅固定) dA/dy = 0 A = a₀ (対称性) dA/dy = 0 (対称点) dΦ/dy = 0 dA/dy = 0 dΦ/dy = 0 (対称点)
位置条件物理的意味
\(y = 0\)\(A(0) = a_0\)ベクトルポテンシャル振幅を規定（解の振幅固定）
\(y = 0\)\(\partial_y A = 0\)フィラメント中心で磁場 \(B_{0z}=0\)（対称性）
\(y = 0\)\(\partial_y \Phi = 0\)フィラメント中心で電場 \(E_{0y}=0\)（対称性）
\(y = L_{1/2}=L/2\)\(\partial_y A = 0\)逆向き電流の入射イオンフィラメント中心で磁場 \(B_{0z}=0\)（対称面、\(B\) は奇関数）
\(y = L_{1/2}=L/2\)\(\partial_y \Phi = 0\)入射イオンフィラメント中心で電場 \(E_{0y}=0\)（対称面）

5つの境界条件が、\(2N+3\) 個の未知数（\(N+1\) 個のA，\(N+1\) 個の\(\Phi\)，\(L_{1/2}\)） に対して、\(2(N-1)\) 個の内部方程式と合わせて閉じた系を作る。

Chebyshevスペクトル法

Chebyshev-Gauss-Lobattoノード \(x_k = \cos(k\pi/N),\; k=0,\ldots,N\) を 物理座標 \(\tilde{y} = L_{1/2}(1-x)/2\) にマップし、 標準区間 \([-1, 1]\) 上の微分行列 \(\mathbf{D}\) を経由して 物理空間の微分を行列演算で表現する。

Chebyshev微分行列

\[ D_{ij} = \begin{cases} \dfrac{c_i}{c_j}\dfrac{(-1)^{i+j}}{x_i - x_j} & i \neq j \\[8pt] \dfrac{(1+2N^2)/6}{} & i = j = 0 \\[4pt] -\dfrac{(1+2N^2)/6}{} & i = j = N \\[4pt] -\dfrac{x_j}{2(1-x_j^2)} & \text{otherwise} \end{cases} \quad c_i = \begin{cases}2 & i=0\text{ or }N \\ 1 & \text{otherwise}\end{cases} \]

座標変換

\(x \in [-1, 1]\) から \(\tilde{y} \in [0, L_{1/2}]\) へのマップは：

\[ \tilde{y} = \frac{L_{1/2}}{2}(1 - x), \qquad \frac{d}{d\tilde{y}} = \frac{1}{dy/dx} \frac{d}{dx}, \quad dy/dx = -\frac{L_{1/2}}{2} \]

したがって物理空間の微分行列は：

\[ \mathbf{D}_{\rm phys} = \frac{\mathbf{D}_{\rm std}}{dy/dx}, \qquad \mathbf{D}^2_{\rm phys} = \frac{\mathbf{D}^2_{\rm std}}{(dy/dx)^2} \] 
def _chebyshev_diff_matrix(N: int) -> tuple[NDArray, NDArray]:
    x = np.cos(np.arange(N + 1) * np.pi / N)   # Gauss-Lobatto ノード
    D = np.zeros((N + 1, N + 1))
    p = np.ones(N + 1); p[0] = 2.0; p[N] = 2.0
    for i in range(N + 1):
        for j in range(N + 1):
            if i != j:
                D[i, j] = (-1) ** (i + j) * p[i] / (p[j] * (x[i] - x[j]))
    D[0, 0]  = (1 + 2*N**2) / 6.0
    D[N, N]  = -(1 + 2*N**2) / 6.0
    for j in range(1, N):
        D[j, j] = -x[j] / (2 * (1 - x[j]**2))
    return D, x

線形分散関係による初期推定値

Newton法の収束性のため、線形分散関係から \((A, \Phi, L_{1/2})\) の良い初期推定値を構成する。 \(\Phi = A = 0\) 周りで密度を線形化すると：

\[ \frac{d^2}{d\tilde{y}^2}\begin{pmatrix}\Phi \\ A\end{pmatrix} = \begin{pmatrix}C_{PP} & -C_{AP} \\ C_{AP} & C_{AA}\end{pmatrix} \begin{pmatrix}\Phi \\ A\end{pmatrix} \]

係数：

\[ C_{PP} = \frac{1}{T_e} + \frac{1-\eta}{T_{inc}} + \frac{\eta}{T_{ref}} \] \[ C_{AP} = \frac{\beta_e}{T_e} + \frac{(1-\eta)\beta_{inc}}{T_{inc}} + \frac{\eta\beta_{ref}}{T_{ref}} \] \[ C_{AA} = -\left(\frac{\beta_e^2}{T_e} + \frac{(1-\eta)\beta_{inc}^2}{T_{inc}} + \frac{\eta\beta_{ref}^2}{T_{ref}}\right) \]

モード \(\Phi = r \cdot A\) の比 \(r\) が満たす2次方程式（Vanthieghem 2018と同じ構造）：

\[ C_{AP}\, r^2 + (C_{AA} - C_{PP})\, r + C_{AP} = 0 \]

2根のうち \(k^2 = -(C_{AP} r + C_{AA}) > 0\) を満たす根を選ぶ。 半周期の初期推定値：\(L_{1/2}^{\rm guess} = \pi / k\)。 振幅プロファイルの初期値：\(A^{(0)}_j = a_0^{\rm start} \cos(\pi(1-x_j)/2)\)。

Newton継続法（ホモトピー）

小振幅 \(a_0^{\rm start} = 0.01\) から目標振幅 \(a_0^{\rm target}\) まで 段階的に振幅を増大させながら Newton 法を繰り返す（continuation method）。 大振幅では直接の Newton 法が収束しないため、前ステップの解を初期値として使うことで 安定した収束を実現する。

a₀ = 0.01 → 0.05 → 0.10 → ... → a₀_target ↓ Newton ↓ Newton ↓ Newton ↓ Newton u₀ u₁ u₂ u_final (initial (prev sol. (prev sol. (solution) guess) × scale) × scale)

ステップ間のスケーリング（線形外挿）:

if i > 0:
    u_guess[:2*N + 2] *= current_a0 / a0_ramp[i - 1]
sol = root(_residual, u_guess, args=(current_a0,), method="lm")
u_guess = sol.x

scipy.optimize.root の Levenberg-Marquardt 法（method="lm"）を使用。 LM法は過決定系・特異点近傍でも安定して動作するため、 非線形スペクトル方程式の解法に適している。

後処理と対称拡張

Newton法で得た半周期解を1周期分に拡張する。 物理的な対称性から：

  • \(B_{0z}, E_{0y}\) — 交互フィラメント系のため反対称（奇関数）
  • \(n_e, n_{inc}, n_{ref}\) — 密度は対称（偶関数）
  • \(y\) 座標 — 0 から \(2L_{1/2}\) まで単調増加
def _mirror_odd(v):   # B, E の反対称拡張
    return np.concatenate([v, -v[-2::-1]])

def _mirror_even(v):  # 密度の対称拡張
    return np.concatenate([v, v[-2::-1]])

# y は折り返し後も単調増加（2*L_half - y_half[-2::-1]）
y_full = np.concatenate([y_half, 2.0 * L_half - y_half[-2::-1]])
境界での厳密施行: Newton法の収束残差により \(B_{0z}[0]\), \(B_{0z}[N]\), \(E_{0y}[0]\), \(E_{0y}[N]\) がわずかに非ゼロになる場合がある。折り返し点でのヒゲ（非滑らか点）を防ぐため、 ポスト処理で境界値を厳密に0にセットする： 
B0z[0] = 0.0; B0z[N] = 0.0
E0y[0] = 0.0; E0y[N] = 0.0

残差関数の構造

解ベクトル \(\mathbf{u} \in \mathbb{R}^{2N+3}\) のレイアウト：

u = [ A[0], A[1], ..., A[N], Phi[0], Phi[1], ..., Phi[N], L_half ] ← N+1 個 → ← N+1 個 → ← 1個 →

残差ベクトルのレイアウト：

インデックス方程式物理的意味
res[0]\(A[0] - a_0 = 0\)BC: A の振幅固定
res[1..N-1]\(\mathbf{D}^2_{\rm phys} A - \text{rhs}_A = 0\)Ampere（内部ノード）
res[N]\((\mathbf{D}_{\rm phys} A)[N] = 0\)BC: \(dA/dy = 0\) at \(L_{1/2}\)
res[N+1]\((\mathbf{D}_{\rm phys} \Phi)[0] = 0\)BC: \(d\Phi/dy = 0\) at \(0\)
res[N+2..2N]\(\mathbf{D}^2_{\rm phys} \Phi - \text{rhs}_\Phi = 0\)Poisson（内部ノード）
res[2N+1]\((\mathbf{D}_{\rm phys} \Phi)[N] = 0\)BC: \(d\Phi/dy = 0\) at \(L_{1/2}\)
res[2N+2]\((\mathbf{D}_{\rm phys} A)[0] = 0\)BC: \(dA/dy = 0\) at \(0\)

計5つの境界条件 + \(2(N-1)\) 個の内部方程式 = \(2N+3\) 個（未知数と一致）。 全残差に \((dy/dx)^2\) を乗じてスケーリングし、数値的なバランスを保つ。
