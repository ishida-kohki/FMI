マッハ数基準のパラメータ構築

代表パラメータとしてマッハ数を1つ決めれば、速度 → 温度 → 各種 β の順で
3成分SNRプラズマ平衡の全パラメータが一意に決まる前向き設計器の解説

概要

3成分SNRプラズマ平衡ソルバー（solve_snr_equilibrium）と PIC シミュレーション config は、本来 ush, sigma, mime, alpha, betae/i/r といった量を個別に手で 設定する。これは物理的に過剰パラメータ化されており、各値の導出根拠が 読み取りにくい。

本モジュール fmi.mach_parameters は、唯一のアンカーを イオンAlfvénマッハ数 \(M_A\) と イオン音速マッハ数 \(M_S\) に定め、そこから一貫した規則で ソルバー入力 \((\eta, \beta_{inc}, \beta_{ref}, T_e, T_{inc}, T_{ref})\) と PIC config の [parameter] 値を両方生成する。

設計の出発点: 「マッハ数を代表パラメータに決めれば、速度 → 温度の順で 他パラメータが自動的に決まるので、マッハ数を基準にパラメータ全体を構築するとわかりやすい」 — 指導教員のコメント。本資料はこれを実装した前向き設計器の導出チェーンと検算をまとめる。
実装: src/fmi/mach_parameters.py ― MachConfig（入力点）, build_solver_params（ソルバー入力）, build_pic_config（PIC config）。回帰テスト tests/test_mach_parameters.py。
本プロジェクトの決定（2026-06、非磁化基準を採用）: SNR 電流フィラメント平衡と線形固有値解析は非磁化（\(\sigma=0\)）で構築する。 根拠:
  • 外部磁場を平衡に入れない: Jikei+ 2024 の外部磁場はイオンビーム （ドリフト \(x\)）に垂直。ドリフトに直交する平均場は成分ごとに異なる motional 力 \(q\,\mathbf u_s\times\mathbf B\) を生み、3成分差動ドリフトでは単一の \(\langle E\rangle\) で同時に打ち消せず静的周期平衡が存在しない （面内 \(y\)・面外 \(z\) いずれも非両立）。よって平衡に外部磁場を設定しない。
  • 自己場が支配的: 自己生成フィラメント磁場 peak \(|B_{0z}|\approx0.16\) に対し仮想ガイド場 \(\sqrt\sigma=0.05\)、比約 3.2。フィラメント構造の駆動源は 対向流であり背景磁場ではないので、\(\sigma=0\) 平衡が本質を捉える。
  • パラメータは音速マッハ基準: 非磁化では \(\beta_A\) が無く \(M_A\) は使えない。 速度は \(\beta_{sh}=V_{sh}/c\) を直接アンカーし、温度は音速マッハ \(M_S\) で決める （下の「磁化/非磁化の分岐」参照）。数値は磁化版と機械精度で一致する。
磁化効果（\(\sigma=0.0025\) で \(\Omega_{ce}/\gamma\approx8\) → 電子は磁化）が必要な段では、 平衡ではなく線形演算子に面外ガイド場 \(\sqrt\sigma\) を加える補正で扱う。

なぜマッハ数を基準にするか

プラズマの状態は「速度スケール」と「温度スケール」で決まる。マッハ数は両者を 無次元の物理的な比として表すので、これを固定すれば残りが従属的に決まる。

マッハ数定義何を固定するか
\(M_A = V_{sh}/v_{A,i} = \beta_{sh}/\beta_{A,i}\)衝撃波速度 / イオンAlfvén速度 速度スケール（→ ドリフト \(\beta_{inc}, \beta_{ref}\)）
\(M_S = V_{sh}/c_{s,i} = \beta_{sh}/\beta_{cs,i}\)衝撃波速度 / イオン音速 温度スケール（→ \(T_{inc}, T_{ref}\)）

マッハ数は速度比なので \(c\) で割っても同じ（\(V_{sh}/v_{A,i}=\beta_{sh}/\beta_{A,i}\)）。 以降の作業変数はすべて \(\beta\)（\(c=1\)）で書く。

\(M_A\) を決めると（磁化 \(\sigma\) が既知なら）衝撃波速度 \(\beta_{sh}\) が決まり、 鏡面反射の規約からイオンドリフトが決まる。次に \(M_S\) を決めると、同じ \(\beta_{sh}\) を 音速で割ってイオン温度が決まる。電子温度だけは独立ノブとして別に与える （現行ランが \(\beta_e=8\) を \(M_A/M_S\) と独立に設定する流儀と整合）。

速度: \(\beta_{sh}\) とドリフト 式 (1)–(4)

磁化 \(\sigma\) と質量比からイオンAlfvén速度 \(\beta_{A,i}=v_{A,i}/c\) が決まり、\(M_A\) を掛けて 衝撃波速度 \(\beta_{sh}=V_{sh}/c\) を得る。

\[ \text{(1)}\quad \beta_{A,i} = \sqrt{\frac{\sigma}{m_i/m_e}} \qquad \text{(2)}\quad \beta_{sh} = M_A \cdot \beta_{A,i} \]

鏡面反射の規約では、入射流と反射流の相対ドリフトが衝撃波速度に等しい （\(2\,\beta_{d} = \beta_{sh}\)、\(\beta_d\) は相対ドリフトの半分）。シム系（電子静止系）でのイオンドリフトは:

\[ \text{(3)}\quad \beta_{d} = \frac{\beta_{sh}}{2} \qquad \text{(4)}\quad \beta_{inc} = \frac{-2\eta\,\beta_{d}}{1-(1-2\eta)\beta_{d}^2},\quad \beta_{ref} = \frac{+2(1-\eta)\,\beta_{d}}{1+(1-2\eta)\beta_{d}^2} \]
式 (4) は PIC main.cpp:61-62（vdi, vdr）と同式。電子ドリフト \(\beta_e\) はソルバー側が電流中性条件 \(\beta_e = (1-\eta)\beta_{inc} + \eta\beta_{ref}\) から自動導出する （snr_equilibrium.py:110）。設計器は \(\beta_e\) を返さない。鏡面反射の 定義から \(\beta_e \approx 0\)（電子静止系）になるのが正しい挙動で、検算で確認する。

温度: 音速マッハから \(T\) 式 (5)–(6)

同じ \(\beta_{sh}\) を音速マッハ \(M_S\) で割るとイオン音速 \(\beta_{cs,i}=c_{s,i}/c\) が決まる。 音速の定義 \(\beta_{cs,i} = \sqrt{\gamma}\,\beta_{th,i}\) と規格化 \(\tilde T_{inc} = m_i\,\beta_{th,i}^2\) から温度が出る。

\[ \text{(5)}\quad \beta_{cs,i} = \frac{\beta_{sh}}{M_S} \qquad \text{(6)}\quad \tilde T_{inc} = \frac{m_i}{m_e}\,\beta_{cs,i}^{2}\Big/\gamma \]

反射イオン温度は比 Tref_over_Tinc で与える （現行ランは betar = betai なので比は \(1.0\)）。

\[ \tilde T_{ref} = \left(\tfrac{T_{ref}}{T_{inc}}\right) \tilde T_{inc} \]

電子温度（独立ノブ） 式 (7)

電子温度はイオンマッハ数からは決まらず、独立に与える。 排他的に1つだけ指定する3つのノブがある（複数指定や未指定はエラー）:

ノブ式用途
beta_e_plasma\(\tilde T_e = \beta_{th,e}^2 = \sigma\,\beta_e^{plasma}/2\)（プラズマβ） 磁化時。現行ラン betae=8 を再現
beta_te\(\tilde T_e = \beta_{th,e}^2\)（\(\beta_{th,e}=v_{th,e}/c\)） 非磁化向け（プラズマβ が定義できないとき）
Te_over_Tinc\(\tilde T_e = (T_e/T_{inc})\,\tilde T_{inc}\) 温度比で与えたいとき
beta_e_plasma は磁化時（\(\sigma>0\)）のみ有効。\(\sigma=0\) で指定すると \(\beta_{A,e}=0\) でプラズマβ が定義できないため ValueError になる。

マッハ恒等式

プラズマ \(\beta\)（圧力比）の定義 \(\beta_s^{plasma} = 2 \beta_{th,s}^2/\beta_{A,s}^2\) と 音速 \(\beta_{cs} = \sqrt{\gamma}\,\beta_{th}\) を組み合わせると、イオンプラズマ \(\beta\) が 2つのマッハ数の比だけで書ける。

\[ \frac{M_A}{M_S} = \frac{\beta_{cs,i}}{\beta_{A,i}} = \sqrt{\frac{\gamma\,\beta_i}{2}} \quad\Longrightarrow\quad \boxed{\;\beta_i = \frac{2}{\gamma}\left(\frac{M_A}{M_S}\right)^{2}\;} \]

これが指導教員の式 \(\beta = (2/\gamma)(M_A/M_S)^2 \sim (M_A/M_S)^2\) に対応する。 恒等式なので build_pic_config の出力 betai はこの値と機械精度で一致する （回帰テスト test_beta_plasma_matches_mach_identity）。

磁化 / 非磁化の分岐

磁化 \((\sigma>0)\)非磁化 \((\sigma=0)\)

\(M_A\) の意味有効\(\beta_A\to0\) で \(M_A\to\infty\)、無意味

本プロジェクトはこの非磁化列を採用（上記「本プロジェクトの決定」参照）。 非磁化では「背景磁場を考えないなら音速マッハ数のみ考えれば良い」という整理に対応する。 速度アンカーは beta_sh を直接指定（\(M_A\) は不使用）、温度は \(M_S\)、電子温度は beta_te。build_pic_config は needs_direct_temperature=True を返し、将来 PIC を新規設計する際は温度を \(\beta_A\) から切り離して直接指定する初期化 （main.cpp 小改修、vte/vti/vtr）が必要であることを示す（線形解析のみなら無関係）。

API と使い方

from fmi.mach_parameters import MachConfig, build_solver_params, build_pic_config
from fmi.snr_equilibrium import solve_snr_equilibrium

# 代表パラメータを1点決める（本プロジェクト既定: 非磁化・音速マッハ基準）
# 速度は Vsh を直接、温度は M_S、電子温度は vte 直接。M_A は使わない。
cfg = MachConfig(M_S=154.92, beta_sh=0.25, beta_te=0.1,
                 sigma=0.0, eta=0.2, mime=400, gamma=5/3)
# （磁化版 MachConfig(M_A=100, M_S=154.92, sigma=0.0025, beta_e_plasma=8.0)
#   と β・T は機械精度で一致。σ は平衡 ODE に現れないため結果は同一。）

# ソルバー入力を一意に導出
sp = build_solver_params(cfg)
# → {eta, beta_inc, beta_ref, Te, Tinc, Tref}

# そのままソルバーへ
r = solve_snr_equilibrium(**sp, a0_target=0.25)

# PIC config の [parameter] 値（新規ラン設計用）
pic = build_pic_config(cfg)
# → {mime, alpha, sigma, ush, betae, betai, betar, needs_direct_temperature}

PIC config の逆生成

build_pic_config(cfg) は新規ラン設計用に PIC [parameter] 値を返す。 磁化時はプラズマ \(\beta\)、非磁化時は熱速度 \(\beta_{th}\) を直接返す。

\[ \texttt{ush} = \frac{\beta_{d}}{\sqrt{1-\beta_{d}^2}},\qquad \texttt{betae} = \frac{2 \beta_{th,e}^2}{\sigma},\qquad \texttt{betai} = \frac{2 \beta_{th,i}^2}{\sigma/(m_i/m_e)} \]
