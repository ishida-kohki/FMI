Harris解の導出と数値平衡解との対応

3成分SNR電流フィラメント平衡を対称化した極限で、解析的 Harris 電流シート解
（\(B\propto\tanh\), \(n\propto\mathrm{sech}^2\), \(\Phi=0\)）へ帰着することを示す検証ノート

概要

低温 SNR 設定（\(T_e\approx0.01\), \(T_i\approx6\times10^{-4}\)）で数値平衡プロファイルが 「角ばった」形になり、これが正しい解か疑問が生じた。これを確かめるため、 設定を対称化（反射割合 \(\eta=0.5\)、逆流ドリフト \(\beta_{\rm ref}=-\beta_{\rm inc}\)、 等温）した数値平衡解を、その極限で成り立つべき解析的 Harris 解と重ねて比較した。

結論： 数値平衡解は Harris 解の構造（中心の磁場反転 \(\propto\tanh\)、 密度ピーク \(\propto\mathrm{sech}^2\)、\(\Phi\approx0\)）を局所的に再現する。ただし孤立単一シートではなく 周期チェーンであり、シート外の平坦部は Harris の飽和裾に対応する物理的構造である。 低温ほどシートが鋭くなる（sinh-Poisson の冷極限）。「歪み」は非収束ではなく物理的形状。

同じ平衡族の特殊解としての Harris

本ソルバの平衡は、各成分が drifting-Maxwellian の Boltzmann 閉包

\[ n_s(y) \;\propto\; \exp\!\Big[\mp\frac{\Phi(y)-\beta_s A(y)}{T_s}\Big] \]

に従い、Poisson 則 \(\Phi''=\rho\) と Ampère 則 \(A''=j_x\) を満たす Grad–Shafranov 型の族である。古典的 Harris 電流シート

\[ B_z(y)=B_0\tanh(y/L),\qquad n(y)=n_0\,\mathrm{sech}^2(y/L),\qquad \Phi=0 \]

は、この族の 2 成分・対称・\(\Phi=0\) の解析的特殊解にあたる。したがって、SNR 平衡を対称極限へ 持っていけば Harris 解に帰着するはずで、これが数値解の妥当性の傍証になる。

対称化の設定

次のパラメータで対称化する：

量設定帰結
反射割合 \(\eta\)0.5入射・反射が等量
ドリフト\(\beta_{\rm inc}=+\beta,\ \beta_{\rm ref}=-\beta\)（\(\beta=0.1\)）逆流対称
温度\(T_e=T_{\rm inc}=T_{\rm ref}=T\)等温
電子ドリフト\(\beta_e=(1-\eta)\beta_{\rm inc}+\eta\beta_{\rm ref}=0\)電流中性が自動成立

\(\beta_e=0\) なので電子はベクトルポテンシャル \(A\) に応答せず、静電ポテンシャル \(\Phi\) にのみ 応答する（純遮蔽体）。この配置で \(\Phi\) はほぼ消え（数値上 \(|E_{0y}|_{\max}\sim5\times10^{-4}\!-\!7\times10^{-3}\)、 下記のとおり \(|E_{0y}|/|B|\) は数%）、Harris の前提 \(\Phi=0\) に対応する。ただし厳密に 0 ではない。

なぜ \(\Phi\approx0\) と言えるか

まず \(\Phi=0\) は厳密解ではない。\(\Phi=0\) とすると電子は一様 \(n_e=1\) だが、 イオンは \(A\) に沿って変調するため、電荷密度

\[ \rho = n_e-(n_{\rm inc}+n_{\rm ref}) = 1-\frac{\cosh(\beta A/T)}{\langle\cosh\rangle}\neq 0 \]

が残り、Gauss 則 \(\Phi''=\rho\) から有限の \(\Phi\) が立つ。それでも \(\Phi\) が小さいのは、独立な 2 つの理由による。

理由1（対称性）：電荷源は場の 2 次、電流源は 1 次

場の振幅 \(f\equiv\beta A/T\) で展開すると、逆流対称（\(\beta_{\rm inc}=+\beta,\ \beta_{\rm ref}=-\beta\)、等温）では

\[ \underbrace{n_{\rm inc}+n_{\rm ref}\approx 1+\tfrac12\big(f^2-\langle f^2\rangle\big)}_{\text{電荷源：}O(f^2)}\;,\qquad \underbrace{n_{\rm ref}-n_{\rm inc}\approx f-\langle f\rangle}_{\text{電流源：}O(f^1)} \]

2 ビームの 1 次応答 \(\pm\beta A/T\) は電荷密度で相殺し、電流で足し合う。よって \(B\) を作る電流 \(j_x=-\beta(n_{\rm inc}-n_{\rm ref})\) は場の 1 次で tanh 磁場を主導する一方、\(\Phi\) を作る電荷 \(\rho\) は場の 2 次で、最初から一桁小さい。対称性が崩れると 1 次の電荷分離が復活し \(\Phi\) は大きくなる。

理由2（電子遮蔽）：\(\beta_e=0\) 電子が Debye 遮蔽する

電子応答 \(n_e\approx 1+(\Phi-\langle\Phi\rangle)/T_e\) を Gauss 則に入れると（モード \(k\)）

\[ -k^2\Phi_k=\frac{\Phi_k}{T_e}-\delta\rho_{{\rm ion},k} \;\Longrightarrow\; \Phi_k=\frac{\delta\rho_{{\rm ion},k}}{1/T_e+k^2}=\frac{T_e\,\delta\rho_{{\rm ion},k}}{1+k^2T_e} \]

\(1/T_e\) は電子の逆 Debye 長²（\(\lambda_{De}^2=T_e\)）。イオンの残余電荷を電子が短距離で遮蔽し、 \(\Phi\sim T_e\,\delta\rho_{\rm ion}\) に抑える。電子の可動性（Boltzmann 応答）が \(\Phi\) を潰す。

まとめ： \(\Phi\) が小さいのは (1) 対称性で電荷源が場の 2 次に落ちることと (2) \(\beta_e=0\) 電子が Debye 遮蔽することの二重による。数値上 \(|E_{0y}|/|B|\approx1.1\%\,(T{=}0.1)\to3.6\%\,(T{=}0.01)\) で、低温ほど \(f=\beta A/T\) が増えて僅かに大きくなるが 数%に留まる。厳密 Harris の \(\Phi=0\) は「電子も同じ \(\mathrm{sech}^2\) に従う／完全遮蔽する」極限に対応する。
適用範囲の注意（非線形性）： 上の理由1（電荷源が場の \(O(f^2)\)）は弱場 \(\xi\ll1\) の展開で、 Harris が現れる \(\xi\gtrsim1\)（下記「非線形性と Harris 極限」）では成り立たない。\(\Phi\) を小さく保つ頑健な根拠は 理由2（Debye 遮蔽、全 \(\xi\) で有効）で、実際 \(\xi=10\) でも \(|E_{0y}|/|B|\le4.8\%\) に留まる。 なお本系の \(\Phi\) は厳密には 0 でない：Vanthieghem+ 2018 の \(\phi_0=0\) は \(e^-\!/e^+\) の完全ペア対称による厳密結果だが、 本系（電子＋2 イオンビーム）は電子にペア相手がいないため \(\Phi\) が数% 残る。

sinh-Poisson 方程式と解析解

\(\Phi\approx0\) を代入すると密度は

\[ n_{\rm inc}\propto e^{+\beta A/T},\quad n_{\rm ref}\propto e^{-\beta A/T},\quad n_e=\text{const} \]

となり、Ampère 則は sinh-Poisson 方程式に帰着する：

\[ \frac{d^2A}{dy^2}=j_x=-\beta\,(n_{\rm inc}-n_{\rm ref})=-\frac{\beta}{\langle\cosh\rangle}\,\sinh\!\Big(\frac{\beta A}{T}\Big) \]

その孤立（単一シート）解が \(B=-A'\propto\tanh(y/L)\)、 イオン総密度 \(n_{\rm inc}+n_{\rm ref}\propto\cosh(\beta A/T)\propto\mathrm{sech}^2(y/L)\) である。 幅 \(L\) は \(\beta,T\) と振幅で決まり、温度が低いほど \(L\) が縮んでシートが鋭くなる。

非線形性と Harris 極限（\(\xi\) パラメータ）

Harris への漸近は温度そのものではなく、非線形（ピンチ）パラメータ \(\xi\) が支配する （Vanthieghem+ 2018, Eq. 17–25）:

\[ \xi \equiv \frac{\gamma_0\beta_0 a_0}{T_0}\ \ (\text{非相対論 }\gamma_0\!\approx\!1:\ \xi\approx\beta a_0/T), \qquad \lambda_0=\frac{2\sqrt{T_0}}{\beta_0\gamma_0}\,K\!\big[-\sinh^2(\xi/2)\big]\,\frac{c}{\omega_p} \]

\(a_0=(e/mc^2)\max A_{0x}\) はベクトルポテンシャル振幅、\(K\) は第1種完全楕円積分。解は Jacobi パラメータ \(\kappa=\coth(\xi/2)\) の cnoidal 波で、2つの極限を持つ:

極限条件プロファイル
弱場\(\xi\to0\)（\(\kappa\to\infty\)）正弦波的（\(\lambda_0=\pi\sqrt{T_0}/\beta_0\gamma_0\)）
強ピンチ\(\xi\gg1\)（\(\kappa\to1^+\)） Harris：\(n_0\to N e^{\xi}\mathrm{sech}^2(uy)\)、well-separated な中性シートの周期鎖

すなわち Harris 解は強非線形極限 \(\xi\gg1\) で局所的に回復する。この視点で本ノートの温度スキャン （\(a_0=0.25\) 固定）を測ると \(\xi=\beta a_0/T\) は次のとおり:

非線形スキャン（\(\xi\) を上げると Harris へ）

\(T=0.02\) 固定で \(a_0\) を上げ \(\xi\) を 1.25→5→10 と増やすと、\(\kappa\to1\)、密度が鋭いスパイク＋広い平坦谷 （well-separated シート）となり Harris へ漸近する。B0z も tanh 的な広い飽和平坦部を持つ。

数値解の求め方

  1. 対称パラメータ（\(\eta=0.5,\ \beta_{\rm inc}=+0.1,\ \beta_{\rm ref}=-0.1,\ T_e=T_{\rm inc}=T_{\rm ref}=T\)、 \(a_0=0.25\)）で solve_snr_equilibrium を呼び、周期平衡を Chebyshev + Newton 継続法で解く。
  2. 温度を \(T=0.1\to0.03\to0.01\)（warm→cold）とスキャンする。
  3. 各解について、密度ピーク（＝電流シート中心）を \(\zeta=0\) に巻き直し、1 シートを取り出す（\(\zeta\equiv y-y_{\rm sheet}\)、非線形パラメータ \(\xi\) とは別物）。
  4. 解析 Harris \(B_0\tanh(\zeta/L)\) と \(n_0\,\mathrm{sech}^2(\zeta/L)+c\) を数値 1 シートに合わせ（振幅・幅の整合）、重ね描きする。
  5. ソルバ自身の Chebyshev 微分で native 残差を測り、描いている解が方程式を満たす（収束済み）ことを担保する。

プロファイルの解釈

磁場 \(B_{0z}\)：中心反転は tanh、外側は平坦部

シート中心（\(\zeta=0\)）で \(B_{0z}\) が符号反転し、その傾きは解析 tanh と一致する。 一方、シートから離れると数値解は \(B\approx\)一定の平坦部を持ち、周期端で再び反転する。 これは孤立 Harris の飽和裾 \(B\to\pm B_0\) の周期版であり、周期チェーン構造の帰結である。

密度 \(n_{\rm inc}+n_{\rm ref}\)：シート中心でピーク

シート中心で密度がピークを持ち（Harris の \(\mathrm{sech}^2\) ピーク）、シート間で凹む。 低温ほどピークが鋭く高くなる（\(n_0:0.009\to0.48\)）。中心付近の形は \(\mathrm{sech}^2\) に対応するが、 数値解は頂部が平坦で裾に凹みを持つ（周期解＝cnoidal 型で、孤立 \(\mathrm{sech}^2\) は長周期極限）。

「歪み」の正体： シート外の平坦部（\(\rho,\ j_x\) が平均値に張り付き \(B,E\) の傾きがゼロになる領域）は、 Harris の飽和裾に対応する物理的構造である。低温でシートが薄く鋭くなるのも sinh-Poisson の冷極限として自然。 数値誤差や非収束ではない。

検証

  • 収束： 全温度で native Chebyshev 残差 resA \(\le7.6\times10^{-8}\)（補間なしの厳密残差）。描いている解は方程式を満たす。
  • Harris 前提： \(|E_{0y}|_{\max}\lesssim7\times10^{-3}\) で \(\Phi\approx0\)。対称化により静電場がほぼ消えることを確認。
  • 非対称 SNR 冷解も収束する： canonical SNR（\(\eta=0.2\), drift \((-0.05,0.2)\), \(T_e=0.01,T_i=6\times10^{-4}\)）を 正しい seed（frame-homotopy）で解くと \(\lambda_0=7.94\)、resA \(=1.6\times10^{-7}\) で収束する。
落とし穴： \(\beta_e=0\) のドリフトを solve_snr_equilibrium に直接渡すと、 線形 seed の結合係数 \(C_{AP}\) が縮退し \(\lambda_0\) が崩壊した spurious 解（resA \(\sim10^{-1}\)）に落ちる。 scipy.optimize.root(lm) はこの崩壊解でも success=True を返すため、 native 残差の独立チェックが必須。

限界と留意点

  • Harris-like であって厳密 Harris ではない： 可動な Boltzmann 電子があるため \(\Phi\) は厳密に 0 ではなく \(O(10^{-3})\) 残る。厳密 \(\Phi=0\) は電子が完全遮蔽する極限。
  • Harris には強非線形が必要： Vanthieghem+ 2018（Eq. 24–25）どおり Harris は \(\xi=\gamma_0\beta_0 a_0/T_0\gg1\) の強ピンチ極限で回復する。温度スキャン図は \(\xi\lesssim2.5\) で弱〜中程度に留まるため、真の Harris は 非線形スキャン（\(a_0\) を上げ \(\xi\!\sim\!10\)）で確認した。
  • 周期チェーン vs 孤立シート： 本ソルバは周期境界（\(A(0)=a_0,\ A'=0\)）を課すため、解は交互フィラメントの 周期チェーンになる。古典的な孤立単一 tanh シート（\(B\to\pm B_0\) の漸近、正味電流あり）はパラメータ調整では到達できず、 周期 \(\lambda_0\to\infty\)（非周期化）の別実装が要る。
  • 解析解の振幅・幅は数値 1 シートへ合わせた重ね描きであり、目的は形状対応の目視確認（R² 適合ではない）。
