線形演算子における密度の扱い

質量流束変数への変換は固有値を変えない — そして相対密度版が短波長の偽モードを 生んでいたという訂正。2026-08-21 作成。

要約

1. 変数変換では偽モードは消せない。 質量流束 \(u_s=n_{s0}\delta v_s\) を使えば 1/n0 は完全に消えるが、 これは離散演算子のレベルで厳密な相似変換であり、固有値は機械精度で一致する。 変数変換という方向は原理的に閉じている。

2. 以前の「密度勾配が短波長モードを作る」という結論は誤りだった。 カットオフに張り付く現象は相対密度版だけの性質であり、 絶対密度版では起きていない。以前の測定はすべて相対密度版で行われていた。

3. 絶対密度版は収束する。ただし収束先が流体近似の外にある。 ppp≥192 で 7 桁一致し、平衡の解像度 Npoints を 4 倍に変えても動かない。 数値的には真の固有値である。しかしそのモードは \(k_y\lambda_{De}=3.65\)、 すなわち電子デバイ長の 1/3.65 の波長にある。この波長では Landau 減衰が支配するため、 数値的に正しくても物理的な成長率ではない。

絶対密度版と相対密度版

同じ線形固有値問題を、密度摂動の変数の取り方だけ変えて実装した 2 つの版がある。

連続な数学としては厳密な相似変換なので固有値は不変である。 ところが離散化すると別物になる。相対版は \(\partial_y\ln n_{s0}\) を D @ log(n0)（log を取ってからスペクトル微分）として実装するが、 これは絶対版の diag(1/n0) @ D とは異なる離散化である。

この差が、nmin=1.86e-3 という穏やかな条件でも相対版を壊していた。 詳細は §相対密度版の欠陥。

発端: 1/n0 を消せないか

線形演算子で密度が入る場所は 2 種類ある。

形現れる式性質
掛け算 \(n_{s0}\times\)連続式、Ampère（電流）有界。無害
割り算 \(1/n_{s0}\times\)運動 y の圧力項、背景場力項n0→0 で発散

1/n0 が現れるのは、運動量方程式を \(m_s n_{s0}\) で割って \(\partial_t\delta v_s=\dots\) の形にするからである。 そもそも割らなければよいのではないか、というのが出発点。

質量流束変数による定式化

速度 \(\delta v_s\) の代わりに質量流束を状態変数に取る。

\[ u_{sx}\equiv n_{s0}\,\delta v_{sx},\qquad u_{sy}\equiv n_{s0}\,\delta v_{sy} \]

\(n_{s0}\) は時間に依存しないので \(m_sn_{s0}(-i\Omega_s)\delta v_{sx}=m_s(-i\Omega_s)u_{sx}\) となり、運動量方程式は \(m_s\) で割るだけでよい。結果は 

連続:    ω δn = kx u_x + kx v0 δn − i ∂_y u_y

運動 x:  ω u_x = kx v0 u_x + i(q/m) n0 δE_x + i(q/m) B0z u_y + (kx γT/m) δn

運動 y:  ω u_y = kx v0 u_y + i(q/m) n0 δE_y − i(q/m) B0z u_x
                − i(q/m) n0 v0 δB_z + i(q/m)(E0y − β B0z) δn − i(γT/m) ∂_y δn

Ampère:  ω δE_x = i ∂_y δB_z − i Σ q(u_x + v0 δn)
         ω δE_y = kx δB_z − i Σ q u_y

1/n0 が完全に消える。 しかも相対密度版と違って \(\partial_y\ln n_{s0}\) も出てこない。 n0 は掛け算としてのみ現れ、係数はすべて有界である。

厳密相似であることの証明

変換行列を、速度ブロックにだけ \(\mathrm{diag}(n_{s0})\) を置いた対角行列とする。

\[ S=\mathrm{diag}\big(\underbrace{I}_{\delta n},\ \underbrace{\mathrm{diag}(n_{s0})}_{\delta v_x},\ \underbrace{\mathrm{diag}(n_{s0})}_{\delta v_y},\ \dots,\ \underbrace{I,I,I}_{E_x,E_y,B_z}\big) \]

このとき 離散演算子のレベルで \(L'=SLS^{-1}\) が厳密に成り立つ。 対角行列同士の積 \(\mathrm{diag}(n_0)\,\mathrm{diag}(1/n_0)=I\) が 離散化誤差を伴わずに打ち消し合うためである。

ブロック元の L\(SLS^{-1}\)流束形
連続 ← vy\(-iD\,\mathrm{diag}(n_0)\) \(-iD\,\mathrm{diag}(n_0)\mathrm{diag}(1/n_0)=-iD\)\(-iD\)
運動x ← n\(\frac{k_x\gamma T}{m}\mathrm{diag}(1/n_0)\) \(\mathrm{diag}(n_0)(\cdots)\mathrm{diag}(1/n_0)\cdot 1=\frac{k_x\gamma T}{m}I\) \(\frac{k_x\gamma T}{m}I\)
運動y ← n\(-i\frac{\gamma T}{m}\mathrm{diag}(1/n_0)D\) \(-i\frac{\gamma T}{m}D\)\(-i\frac{\gamma T}{m}D\)
運動x ← Ex\(i\frac{q}{m}I\) \(i\frac{q}{m}\mathrm{diag}(n_0)\)\(i\frac{q}{m}\mathrm{diag}(n_0)\)
Ampère ← vx\(-iq\,\mathrm{diag}(n_0)\) \(-iq\,I\)\(-iq\,I\)

相似変換なので固有値は 1 つも変わらない。 偽モードが離散演算子の真の固有値である限り、そのまま残る。

以前の測定は「間違った固有値」ではなかった。 汚染された演算子の正しい固有値のうち、最速のものが偽モードだったというのが実態である。 最速モードだけを見る解析手順が、この失敗を見逃す原因になった。

なぜ相対版だけ壊れるのか

相対版が持ち込む唯一の新しい項が D @ log(n0) である。

1/n0 の実装微分行列にかかるか高調波を生むか
絶対版diag(1/n0)いいえ（対角行列）生まない
相対版D @ log(n0)はい生む

nmin = 1.86e-3 なので \(\ln n_0\) の変動幅は \(\ln(1.26/1.86\!\times\!10^{-3})=6.5\) あり、 勾配は \(\max|\partial_y\ln n_0|=6.24\)、勾配スケール長は 0.16 c/ωpe しかない。 これをスペクトル微分すると Gibbs 現象で高調波が励起される。

以前の対照実験で「密度を一様にすると収束する」という結果が出たことも、これで説明がつく。 密度勾配を消すと D @ log(n0) の項自体が消えるからである。 あの実験は「密度勾配が物理的に短波長モードを作る」ではなく、 「密度勾配が相対版の離散化を壊す」ことを示していた。

残る問題: 流体近似の妥当範囲

収束したモードが物理的とは限らない。

電子デバイ長は（\(c=1\)、\(m_ec^2\) 規格化で）

\[ \lambda_{De}=\frac{v_{te}}{\omega_{pe}}=\sqrt{T_e}=\sqrt{1.4507\times10^{-2}} =0.1204\ \ c/\omega_{pe} \]

収束したモードは n=32、すなわち

\[ k_y=32\,k_0=30.3\ \omega_{pe}/c,\qquad \lambda=0.2074\ c/\omega_{pe},\qquad \boxed{k_y\lambda_{De}=3.65} \]

流体近似が妥当なのは \(k\lambda_{De}\lesssim1\) の範囲である。 \(k\lambda_{De}=3.65\) では実際には Landau 減衰が支配し、 流体モデルが予言する成長は起きない。

問題の性質が変わった。 「解けない」から「解けるが、答えが流体モデルの適用範囲外」になった。 対処法も変わる。カットオフを恣意的に決めるのではなく、 \(k\lambda_{De}\lesssim1\)（本平衡では n ≲ 8.8）という物理的な基準で モードを選別すればよい。以前提案していた「Nyquist の 1/4」のような 恣意的な閾値と違い、根拠がある。

平衡解像度への依存性

収束した \(\gamma=9.203116\times10^{-4}\) の調波 n=32 が、 平衡ソルバーの解像度 N_points=64 のちょうど半分と一致していた。 背景表現の帯域幅が決めている産物である可能性を排除するため、 線形格子 ppp=288 を固定して平衡側だけを変えた（scratchpad/eq_resolution.py）。

n=32 は平衡の解像度に依存しない。 Npoints を 4 倍にしても γ は 7 桁一致し、n も動かない。 背景表現の産物ではなく離散演算子の真の固有値である。 背景の実効帯域は 50 で、モードの n=32 はその内側に収まっている。

したがって数値的な疑いは解消した。残る論点は \(k_y\lambda_{De}=3.65\) という物理的な妥当性だけである。

次にやること

  1. 絶対密度版で kx 分散関係を引き直す— 準定常平衡の結論は相対版に基づいていたため、全面的にやり直す必要がある。
  2. モード選別の基準を \(k_y\lambda_{De}\lesssim1\) にする— 恣意的なカットオフ比ではなく物理的な根拠に基づく基準に置き換える。
  3. 相対密度版の位置づけを見直す— nmin が中程度（1e-3 級）なら絶対版が正しい。 相対版が必要なのは nmin が極端に小さい場合に限られるが、 その領域では相対版自体も収束しないことが既に分かっている。 相対版の使いどころが実質的に無い可能性がある。

変数変換という方向は完全に閉じた。 スペクトルを変えるには物理モデルを変えるしかない。 候補は「平衡に静止環境プラズマを加えて n0 が 0 に落ちないようにする」 「異方性圧力や有限ラーマー半径効果で短波長を切る」である。 ただし \(k\lambda_{De}\) による選別で足りるなら、モデル変更は不要かもしれない。
