SNR平衡における電場 \(E_{0y}\) の空間変動の起源

work/snr_equilibrium_2period.png の \(E_{0y}\) プロファイルが
なぜ複雑に変動するか — Gauss則・冷イオン電荷層・温度依存の解説

概要（この図の謎）

問いは2つ:(1) なぜ \(E_{0y}\) は \(B_{0z}\) より構造が細かいのか、(2) フィラメント端で \(E_{0y}\) が見せる急峻な「段」は何か。結論から言うと、両方とも冷たいイオンが作る 鋭い電荷構造に起因する。以下、Gauss則から順に解く。

E0y を作るのは電荷密度 \(\rho\)

平衡は \(y\) のみに依存し、\(E_{0y}=-d\Phi/dy\)、\(B_{0z}=-dA/dy\)。 各ポテンシャルの源は Maxwell（正規化形）:

\[ \frac{d^2\Phi}{dy^2} = -\rho(y),\quad \rho=n_e-n_{inc}-n_{ref} \qquad \frac{d^2A}{dy^2} = -J_x(y),\quad J_x=\beta_e n_e-\beta_{inc}n_{inc}-\beta_{ref}n_{ref} \]

つまり \(E_{0y}\) の変動 = 電荷密度 \(\rho\) の偏りの写し、 \(B_{0z}\) の変動 = 電流 \(J_x\) の偏りの写し。両者の「素材」が違うことが、見た目の違いの根。 密度は Boltzmann 閉包

\[ n_s \propto \exp\!\big[\mp(\Phi-\beta_s A)/\tilde T_s\big] \]

で与えられ、合成ポテンシャル \((\Phi-\beta_s A)\) に指数的に応答する。

なぜ \(B\) は滑らかで \(E\) は構造的か 高調波

1周期の \(B_{0z},E_{0y},\rho\) を Fourier 分解すると（\(N=256\)、振幅を最大成分で規格化）:

場卓越する高調波（モード番号 : 振幅比）1周期の極値数
\(B_{0z}\)#1 : 1.0,  #2 : 0.31,  #3 : 0.172（ほぼ純基本波）
\(E_{0y}\)#4 : 1.0,  #3 : 0.94,  #5 : 0.83,  #2 : 0.604（高調波リッチ）
\(\rho\)#5 : 1.0,  #4 : 0.96,  #6 : 0.76,  #10 : 0.73さらに鋭い

(1) \(B_{0z}\) が滑らかな理由

\(A\) を作る電流 \(J_x\) はフィラメント化の固有モードそのもので、系が磁気的に支えられる 波長は実質1つ（\(k_0\)）。よって \(A\approx a_0\cos k_0 y\) の単一余弦、 \(B_{0z}=-dA/dy\approx a_0 k_0\sin k_0 y\) → 山1・谷1の2極値。 磁気セクターは結合 \(C_{AA}\sim\beta^2/\tilde T\) が小さく「柔らかい」ため長波長しか持てない。

(2) \(E_{0y}\) が構造的な理由

\(\Phi\) を作る \(\rho\) が高調波だらけになる。三つの効果が重なる:

  • 指数応答 × 冷たいイオン: \(1/\tilde T_{inc}\approx1600\) なので、滑らかな \(A\) でも 指数 \(\exp[-\beta_s A/\tilde T_s]\) が鋭く尖った密度ピークを作り高調波を生む。
  • 準中性の打ち消し残差: 電子が遮蔽して \(n_e\approx n_{inc}+n_{ref}\)。残る \(\rho\) は 大きく鋭い量の小さな差で、急勾配（フィラメント端）に集中する → \(\rho\) はさらに鋭い。
  • 積分のスケーリング: Fourier で \(\Phi_k=\rho_k/k^2\)、\(E_{0y,k}=\rho_k/k\)。 \(E_{0y}\) は \(\rho\) の高調波を \(1/k\) でしか減衰させない（\(\Phi\) は \(1/k^2\)）ため構造が残る。
一言で:両方ともポテンシャルの1階微分だが、源が違う。 \(B_{0z}\) は「滑らかなコヒーレント電流」由来 → 単一波長 → 2極値。 \(E_{0y}\) は「鋭い電荷残差」由来 → 高調波リッチ → 4極値。

フィラメント端の急変：冷イオン電荷層 不連続ではない

\(E_{0y}\) がフィラメント端（\(y/\lambda_0\approx0.1,0.9\)）で見せる急峻な「段」は、 反射イオン領域と入射イオン領域の境界に立つ薄い電荷二重層である。 そこで \(\rho\) が \(+0.24\) に尖り、Gauss則 \(dE_{0y}/dy=\rho\) により \(E_{0y}\) が急に落ちる。

検証結果意味
\(N=64,128,256\) での \(E_{0y}\) 振幅\([-0.027,+0.027]\) で一定収束（アーティファクトでない）
端での \(|dE_{0y}/dy|\) と \(\rho\)ともに \(\approx0.22\)Gauss則と整合（実在の電荷層）
サンプル毎の \(E_{0y}\) 変化\(\le0.003\)/点連続・滑らか（ジャンプなし）
見かけ上「不連続」に見えるのは、(1) 反射イオンが冷たく（\(\tilde T\approx6\times10^{-4}\)）層が極薄、 (2) 元図が \(N=128\)＋2周期タイルで薄い層をまばらな点で描いたため。 実体は急峻だが連続な \(S\) 字遷移で、真の不連続（電荷シート \(\delta\) 関数）ではない。

温度依存：暖めると滑らかになる

層の薄さはイオン温度で決まる（層幅 \(\propto\sqrt{\tilde T}\)）。\(M_S\) を下げて暖めると:

\(M_S\)\(\tilde T_i\)端の最大勾配 \(|dE_{0y}/dy|\)
154.92（既定）\(6.25\times10^{-4}\)0.21（急峻・段状）
80\(2.34\times10^{-3}\)0.089（緩む）
40\(9.38\times10^{-3}\)0.018（滑らか）
この温度依存性こそ「数値アーティファクトではなく物理」の決定的証拠。 アーティファクトなら温度に反応しない。滑らかな \(E_{0y}\) が欲しければ反射イオンを暖める （実効マッハを下げる／\(T_{ref}/T_{inc}\) を上げる）。

補足：\(E\) と \(B\) の符号関係

半周期で \(A(y)\) は単調なので \(\Phi=\Phi(A)\) と見られ、 \(E_{0y}/B_{0z}=d\Phi/dA\)。同じ冷イオン非線形性がここにも効く。

暖かい（線形）領域では \(\Phi\propto A\) ゆえ \(E_{0y}\propto B_{0z}\) で符号がロックするが、 冷たい（非線形）領域では \(\Phi\) が \(A\) に無い電荷層構造を持ち、 \(d\Phi/dA\) が符号反転して所により \(E\) と \(B\) の符号が食い違う。 「符号一致」は暖かい/線形領域に特有の性質で普遍法則ではない。

まとめ

E0y の変動の起源 ──────────────────────────────────────────────── E0y = −dΦ/dy, Φ'' = −ρ （Gauss則） │ ├─ ρ は冷イオン(T̃≈6e-4)の指数応答で鋭い │ → 高調波リッチ → E0y は B0z より構造的（4極値 vs 2極値） │ ├─ 反射/入射イオン界面に薄い電荷二重層（ρ尖り +0.24） │ → E0y が急峻な段（連続・Gauss整合・振幅収束） │ └─ 温度を上げると層が広がり E0y は滑らかに（∝√T̃）
  • \(E_{0y}\) の変動は電荷密度 \(\rho\) の偏りを Gauss則で写したもの。
  • \(B_{0z}\) より細かいのは、\(\rho\) が冷イオンの指数応答＋準中性残差で高調波リッチだから。
  • 端の「段」は冷イオン電荷二重層。急峻だが連続（不連続ではない）。
  • すべて冷たいイオンが根。暖めれば滑らかになる（物理であってバグでない）。
