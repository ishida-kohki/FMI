PIC シミュレーションとの平衡解検証

3成分SNRプラズマ電流フィラメント平衡ソルバー（Vanthieghem 2018 拡張）の解を、 独立に走らせた PIC シミュレーション（pic-nix-weibel）の飽和フィラメント期と突き合わせた記録。

概要 / 結論

自己生成磁場・各成分密度・電流の 空間構造と位相関係は平衡解とよく一致した （相関 0.82–0.98）。フィラメント波長は初生成時に理論値とほぼ同スケールで、その後 filament-merging により階段状に粗大化するという PIC の描像を再現した。 唯一 E_y（静電場）は一致せず、これは背景磁場による電子磁化が 非磁化 Boltzmann 平衡に含まれないためと特定でき、次段の σ=0 コントロールランの動機を定量的に裏付けた。

総合判定: フィラメントの構造については「およそ合っている」と結論できる。 B_z・密度・電流の形と位相、交互フィラメント配置、初期波長スケール、merging 系列がすべて整合した。

幾何・座標対応

ソルバーと PIC（in-plane beam, 実質1D-y ラン）の座標は完全に対応する。

平衡ソルバーPIC
ドリフト方向xx（入射 −0.24c / 反射 +0.24c）
空間変調・Weibel 波数yy
自己生成磁場B0z（z, 面外）sim Bz = uf[...,5]
静電場E0y（y）sim Ey = uf[...,1]
系の整合チェック: 電流中性式 \(\beta_e=(1-\eta)\beta_{inc}+\eta\beta_{ref}\) に PIC パラメータを入れると \(\beta_e=0\)。電子静止系で電子ドリフト ≈ 0 と一致し、両者が同じ系を共有することを確認。

データセット選定

当初想定した 2D 本番ラン（σ=0.0025, η=0.2, 4096²）は生スナップショットが削除済みで、 B 場の y プロファイルのキャッシュしか残っていなかった（密度・E_y 比較は不可）。 全モーメント（um）が残る唯一のデータセットである build 1D ランを検証対象に選んだ。

データセット飽和データ密度/E_y/電流判定
ローカル 512² テスト✗ (t≤0.5)—使用不可
2D 本番キャッシュ✓ (t→800)✗ B場のみB_z/λ のみ可

build 1D ラン（Nx=2×Ny=1024, 実質1D-y）は明確な Weibel 発展を示す: dBz/B0 が 0→4.6(t=50)→9.0(t=100)→12.7(t=250)、入射イオン密度に係数4–6のフィラメント変調。 幾何はソルバーが直接モデル化する 1D-y そのもの。

検証手法

  • 飽和ウィンドウの自動選定: \(dB_z^{rms}(t)\) の最初の局所極大（初期 Weibel 飽和、merging 前）を採用。global-max は merging 後の終端に来るため不適。
  • プロファイル抽出: 飽和スナップで x（と z）平均し B_z, E_y, 各種数密度, 電荷電流の y プロファイルを取得。\(\langle n_e\rangle\) で正規化。
  • 位相折り畳み: 支配波長 λ_pic で1周期に折り畳み（位相ビン平均）。複数フィラメントを平均し SNR 向上。
  • 振幅整合: ソルバーの自由振幅 a0 を 1 次元スキャンし PIC の |B_z| ピークに合わせる。
  • 位相整合: 偶関数の入射イオンフィラメント中心（n_inc ピーク）で共通シフトを決定し全量に適用。奇関数 B_z で合わせると半周期＋符号の不定性が出るため使わない。
  • 指標: 各量の Pearson 相関（共通整合・最適整合）と振幅正規化 RMS、λ 相対誤差。

図1: 自己生成磁場 B_z

注目点: 両者とも反対称で、ゼロ点が位相 φ≈0.2, 0.72＝イオンフィラメント中心に一致する。 意味: 「フィラメント中心で電流最大・B_z=0、フィラメント間で B_z 極大」という電流フィラメントの位相構造を平衡解が正しく再現（相関0.98）。PIC は a0 上限の都合で振幅がやや大きいが形は一致。

図2: 種別密度プロファイル

注目点: 入射イオンと反射イオンが半周期ずれた交互フィラメントを作り、PIC と平衡解で位相が一致。電子は局所イオン密度を中和。 意味: 3成分系特有の交互フィラメント配置と各成分の集中/排除を平衡解が捉えている。定量的には平衡解の方がピークが鋭く高い（初期飽和の PIC は未完全ピンチ＋熱的広がり）。

図3: 静電場 E_y と電荷電流 j_x

注目点: j_x はよく一致（相関0.89）するが、E_y は一致しない（最適整合でも0.20）。 意味: 電流チャネル構造は平衡解で再現できる一方、E_y は背景磁場による電子磁化・motional 成分を含み、非磁化静電平衡（E0y=−dΦ/dy）では説明できない。これが σ=0 コントロールランで検証すべき差。

図4: フィラメント波長 λ(t)

注目点: 初生成時 λ≈10 c/ω_pe が理論 λ_0≈7 に近く、その後 10→17→26→51 と階段状に増大。 意味: 理論 λ_0 は線形（初期）スケールの下限として機能し、PIC はそこから出発して filament-merging で粗大化する。あなたの読み取った merging 系列を定量的に裏付ける。

限界と次の一歩

E_y 不一致 → 電子磁化: 背景磁場（θ=90, B0∥y, σ=0.01）が電子を磁化し、 非磁化 Boltzmann closure からずれる。E_y はこの効果に最も敏感。
  • cold-ion ソルバーの硬さ: Te≈0.0025 は指数が飽和しやすい。温度係数(dof)は PIC Maxwellian 定義に依存。
  • a0 上限: スキャン上限 0.6 に張り付き、理論 B_z 振幅(0.43)が PIC(0.91)に届かず。範囲拡張 or N_points 増で改善余地。
  • x 平均1D近似: 最初期飽和でのみ妥当（merging/kink 後は x 構造が立つ）。
  • パラメータ差: 今回は build 1D ラン（σ=0.01, η=0.5）での検証。2D 本番（σ=0.0025, η=0.2）では生データが無く、B_z/λ のみクロスチェック可能。
次の一歩: 背景磁場ゼロ（σ=0）の安価なコントロールラン（小box・低mime、温度を v_A から切り離す初期化）。 E_y 不一致が消えれば、非磁化3成分 Boltzmann 平衡の妥当性が完全に確定する。
