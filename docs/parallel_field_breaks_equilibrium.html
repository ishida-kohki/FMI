衝撃波に平行な背景磁場が静的平衡を壊す理由

SNR 電流フィラメント平衡を非磁化（\(\sigma=0\)）で構築する決定の物理的根拠。
なぜ「ビームに垂直＝衝撃波面に平行」な平均磁場を平衡ソルバーに入れられないのかを、 周期平均した運動量収支から示す。

結論（一言）

ドリフトに直交する平均磁場（＝衝撃波面に平行な背景場）は、成分ごとに 異なる motional 力 \(q_s\,\mathbf{u}_s\times\mathbf{B}\) を生む。3成分（電子・入射イオン・ 反射イオン）のドリフト \(\beta_e,\beta_{inc},\beta_{ref}\) がすべて異なるため、 この力を全成分同時に打ち消す単一の平均電場 \(\langle E_y\rangle\) が存在しない。 したがって静的な周期平衡が存在しない。だから外部磁場は平衡ソルバーに入れず、 \(\sigma=0\) で平衡を構築する。

逆に、衝撃波法線（＝ビームドリフト \(x\)）に平行な背景場なら \(\mathbf{u}_s\times\mathbf{B}=0\) となり、平衡は一切影響を受けない。 破れるのは「ドリフトを横切る成分」だけである。

幾何と「衝撃波に平行」の意味

座標系を固定する。

軸向き物理量
\(\hat{x}\)ビームドリフト方向 ＝ 衝撃波法線 各成分のドリフト \(\beta_s c\)（入射・反射イオンが相対流）
\(\hat{y}\)横方向（衝撃波面内） フィラメントが周期的に並ぶ方向。平衡は \(y\) のみに依存
\(\hat{z}\)面外（衝撃波面内） 自己生成フィラメント磁場 \(B_{0z}(y)\) の向き
衝撃波面 (shock front) = y–z 平面 ┌─────────────────────────────┐ │ ↑ y │ ビーム →→→ x̂ （衝撃波法線） │ │ ● B_0z(z) │ │ ●●●●●●│●●●●●● フィラメント │ 「衝撃波に平行」= y-z 面内 │ │ │ = x に垂直 = ドリフトを横切る │ └────→ z │ 「衝撃波法線に平行」= x̂ = ドリフトと同じ向き └─────────────────────────────┘
用語の対応: 「衝撃波に平行な磁場」とは衝撃波面に平行、すなわち \(y\text{–}z\) 面内の場を指す。これは法線 \(x\)（＝ビームドリフト）に垂直である。 Jikei+ 2024 が外部磁場を「イオンビームに垂直」に置いているのはこの向きで、 垂直衝撃波（\(\mathbf{B}\perp\) 衝撃波法線）の標準的配置に一致する。

平衡の枠組み

各成分 \(s\) は \(x\) 方向に一様ドリフト \(\mathbf{u}_s=\beta_s c\,\hat{x}\) し、密度 \(n_s(y)\)、 温度 \(T_s\)（等温）を持つ。定常・\(y\) 依存の運動量収支のうち、構造を決めるのは \(y\) 方向成分である：

\[ \partial_y \big(n_s T_s\big) \;=\; n_s\,q_s\Big[\,E_y \;+\;\big(\mathbf{u}_s\times\mathbf{B}\big)_y\,\Big] \]

ここで \(\mathbf{B}=B_{0z}(y)\,\hat{z}\)（自己場）とすると \((\mathbf{u}_s\times\mathbf{B})_y = (\beta_s c\,\hat{x}\times B_{0z}\hat{z})_y = -\beta_s c\,B_{0z}\)。 電場 \(E_y\) は Poisson、磁場 \(B_{0z}\) は Ampère で自己整合に閉じ、Boltzmann 型の閉包 \(n_s\propto \exp(-q_s\phi_s/T_s)\) が得られる。これが標準の多成分電流フィラメント平衡であり、 \(E_y\) と \(\beta_s B_{0z}\) が同じ自己場構造に比例するため一貫して解ける。

σ=0（外部場なし）は解ける 解が存在

外部場がなければ場は自己生成 \(B_{0z}(y)\) のみ。対称なフィラメント配置では \(\langle B_{0z}\rangle = 0\)（周期平均でゼロ）。\(y\) 方向運動量収支を1周期で平均すると、 左辺は周期関数の微分なので \(\langle \partial_y(n_sT_s)\rangle=0\)。したがって

\[ 0 \;=\; q_s\Big[\langle E_y\rangle - \beta_s c\,\langle B_{0z}\rangle\Big] \;=\; q_s\,\langle E_y\rangle \quad\Longrightarrow\quad \langle E_y\rangle = 0 \]

すべての成分について \(\langle E_y\rangle=0\) で同時に満たされる。矛盾はなく、 静的周期平衡が存在する。これが現行ソルバーが解いている系である。

外部場を入れると motional 力が入る

ここに衝撃波面に平行な一様背景場、まず代表として面外成分 \(\mathbf{B}_{\rm ext}=B_0\,\hat{z}\) を加える（全磁場は \(B_{0z}(y)+B_0\)）。 \(y\) 方向収支は

\[ \partial_y\big(n_sT_s\big) \;=\; n_s\,q_s\Big[\,E_y - \beta_s c\,\big(B_{0z}(y)+B_0\big)\,\Big] \]

追加された \(-\,q_s\,\beta_s c\,B_0\) が、成分ごとに大きさの異なる一定の横向き力 （motional 力）である。電子・入射イオン・反射イオンで \(\beta_s\) が違うので、 この力は3通りの異なる値をとる。

核心：周期平均が過剰条件になる

同じく1周期で平均する。\(\langle\partial_y(n_sT_s)\rangle=0\) と \(\langle B_{0z}\rangle=0\) より、各成分ごとに次を要求する：

\[ 0 \;=\; q_s\Big[\langle E_y\rangle - \beta_s c\,B_0\Big] \quad\Longrightarrow\quad \boxed{\;\langle E_y\rangle \;=\; \beta_s\,c\,B_0\;}\qquad(s=e,\,\mathrm{inc},\,\mathrm{ref}) \]

ここが要点である。左辺 \(\langle E_y\rangle\) は全成分で共通の1つの量 （場は1つしかない）。ところが右辺 \(\beta_s c B_0\) は成分ごとに違う。 したがって

\[ \langle E_y\rangle = \beta_e c B_0 = \beta_{inc} c B_0 = \beta_{ref} c B_0 \] は \(\beta_e=\beta_{inc}=\beta_{ref}\) でない限り成立しない。3つの差動ドリフトがある以上 解となる \(\langle E_y\rangle\) が存在せず、静的周期平衡は存在しない。

物理的には、各成分の感じる横向き motional 力を平均電場で相殺しようとしても、 相殺できるのは高々1成分ぶんで、残りの成分には正味の横向き力が残る。 残った力は \(E\times B\) ドリフトや偏極を駆動し、系は時間発展してしまう ——静的解に落ち着かない。これが「背景磁場を入れると平衡が壊れる」の中身である。

面内成分 \(\mathbf{B}_{\rm ext}=B_y\hat{y}\) を加えた場合も同様で、 motional 力 \((\mathbf{u}_s\times\mathbf{B})_z=+\beta_s c B_y\) が \(z\) 方向に現れる。 平衡は \(z\) に依存しない（\(\partial_z=0\)）ため、この力を相殺するには \(\langle E_z\rangle=\beta_s c B_y\) が全成分で必要になり、やはり過剰条件で解けない。 結局、ドリフト \(x\) を横切る任意の平均場成分（＝衝撃波面に平行な成分すべて）が 平衡を壊す。

具体数値で見る非両立

現行 SNR ラン（\(\eta=0.2\)、電子静止系で構築）の代表ドリフトを入れると、 過剰条件は次のように互いに矛盾する3つの要求になる：

成分ドリフト \(\beta_s\)要求される \(\langle E_y\rangle/(cB_0)\)
電子\(\beta_e \approx -0.0008\)\(\approx -0.0008\)
入射イオン\(\beta_{inc} \approx -0.050\)\(-0.050\)
反射イオン\(\beta_{ref} \approx +0.198\)\(+0.198\)

1つの \(\langle E_y\rangle\) が同時に \(-0.0008\)、\(-0.050\)、\(+0.198\)（単位 \(cB_0\)）に等しくなる ことはあり得ない。とくに反射イオンは符号まで逆で、最もドリフトが大きいぶん最も強く外れる。 差動ドリフトが本質的な系（＝まさに SNR フィラメント）ほど、背景場は平衡と両立しない。

法線に平行なら壊れない 例外

同じ「背景磁場」でも、衝撃波法線（ビームドリフト \(x\)）に平行な \(\mathbf{B}_{\rm ext}=B_\parallel\hat{x}\) は事情が違う：

\[ \mathbf{u}_s\times\mathbf{B}_{\rm ext} = \beta_s c\,\hat{x}\times B_\parallel\hat{x} = 0 \]

motional 力がそもそも生じないので、\(y\) 方向収支は \(\sigma=0\) の場合と完全に同じ。 平衡は影響を受けない。つまり破れの原因は「磁場があること」自体ではなく、 ドリフトを横切る成分があることである。一般の \(\mathbf{B}_{\rm ext}\) を \(B_\parallel\hat{x}\)（無害）と面内の垂直成分（有害）に分解すれば、後者だけが問題になる。

まとめの対比：
  • 衝撃波法線に平行（\(\parallel\) ビーム）→ \(\mathbf{u}\times\mathbf{B}=0\) → 平衡は保たれる
  • 衝撃波面に平行（\(\perp\) ビーム）→ 成分依存の motional 力 → 静的平衡が存在しない

σ=0 で十分な理由

外部場を落として \(\sigma=0\) で平衡を張っても、物理の本質は失われない：

  • 自己場が支配的。 自己生成フィラメント磁場のピーク \(|B_{0z}|\approx 0.16\) に対し、ガイド場 \(\sqrt{\sigma}=0.05\)（\(\sigma=0.0025\) 相当）。 比 \(\sim 3.2\) で自己場が勝つ。フィラメント形成を駆動するのは対向流であって背景場ではない。
  • スケール分離。 \(\sigma=0.0025\) では電子は FMI 成長時間で磁化する （\(\Omega_{ce}/\gamma\approx 8\)）が、イオンは非磁化（\(\Omega_{ci}/\gamma\approx0.02\)）。 フィラメント構造の骨格は非磁化イオンの対向流が決める。
  • 新規性。 SNR 電流フィラメントの線形解析はほぼ未開拓なので、 まずクリーンな非磁化ベースで足場を固める価値がある。

実装への帰結

平衡ソルバーには外部磁場を入れない。 fmi.snr_equilibrium / fmi.snr_linear は \(\sigma=0\) で構築する。 MachConfig(..., sigma=0.0) を使い、速度は \(V_{sh}/c\)、温度は音速マッハ \(M_S\)、 電子温度は \(v_{te}/c\) で与える（Alfvén マッハ \(M_A\) は使わない）。

磁化効果を後で調べたい場合は、線形演算子にのみ面外ガイド場 \(\sqrt{\sigma}\) を加える（\(v\times B\) 項は既に実装済み、P 偏光・12場構造は保存）。 平衡ソルバーには決して加えない。静的平衡は \(\sigma=0\) のまま、 背景場は摂動の伝播にのみ効かせる、という切り分けである。
