1. 概要・物理背景

このノートブックは FMI（Filamentation Magnetic Instability） の 非線形均衡プロファイルを数値計算し、Vanthieghem et al. (2018) の Figure 1 を再現します。

FMI は、相対論的な電流シートにおいて電磁場が自己一致的に形成される現象であり、 宇宙プラズマ（衝撃波・ジェット）の磁場増幅機構として注目されています。

参考文献： Vanthieghem, A. et al. (2018). Stability and nonlinear saturation of the Weibel/filamentation instability in a relativistic beam-plasma system.

2. 物理モデル：非対称ビームプラズマ系

系は 相対論的ビーム（beam） と 背景プラズマ（plasma） の 2 成分から構成されます。 両成分は逆方向に流れます（ $z$ 軸方向）。

成分温度速度 $\beta = v/c$ローレンツ因子 $\gamma$
ビーム (b) $T_b = 1.0$ $\beta_b = -0.995$（$-z$ 方向） $\gamma_b = 1/\sqrt{1-\beta_b^2} \approx 10.0$
プラズマ (p) $T_p = 0.1$ $\beta_p = +0.995$（$+z$ 方向） $\gamma_p \approx 10.0$
非対称性の意味： $T_b \neq T_p$ であるため「非対称」均衡と呼ばれます。 温度が異なると電場 $E_{0y}$ も有限になります（対称系では $E_{0y} = 0$）。

均衡は $y$ 方向に周期的（ドメイン幅 $\lambda_0$）で、 $z$ 方向一様の 1D 問題として定式化されます。

3. 支配方程式

3.1 Maxwell 方程式（静的均衡）

均衡状態では時間微分がゼロとなり、Ampère 則と Gauss 則は

$$\frac{d^2 A}{dy^2} = \sum_\alpha J_{z,\alpha} = 2\bigl(\gamma_b\beta_b \sinh\xi_b + \gamma_p\beta_p \sinh\xi_p\bigr)$$ $$\frac{d^2 \Phi}{dy^2} = \sum_\alpha \rho_\alpha = 2\bigl(\gamma_b \sinh\xi_b + \gamma_p \sinh\xi_p\bigr)$$

ここで $A$ はベクトルポテンシャル（$B_{0z} = -dA/dy$）、$\Phi$ はスカラーポテンシャル（$E_{0y} = -d\Phi/dy$）です。

3.2 Boltzmann 分布の指数引数

各成分の分布が Maxwell–Jüttner 分布に従うとき、指数引数は

$$\xi_\alpha = \frac{\gamma_\alpha}{T_\alpha}\bigl(\Phi - \beta_\alpha A\bigr)$$

この引数の符号の対称性から、$+y$（進行方向）と $-y$（逆行方向）の 粒子密度比が $e^{+\xi_\alpha}$、$e^{-\xi_\alpha}$ となります。

3.3 境界条件

ドメイン半分 $y \in [0, L/2]$ を解いて後で反転対称化します。

境界条件意味
$y = 0$（中心）$A(0) = a_0$振幅を固定（継続法の制御変数）
$y = 0$$d\Phi/dy = 0$対称性から $E_{0y}(0) = 0$
$y = L/2$（端）$dA/dy = 0$$B_{0z}(L/2) = 0$
$y = L/2$$d\Phi/dy = 0$$E_{0y}(L/2) = 0$

4. 数値手法

4.1 Chebyshev スペクトル法

物理空間 $y \in [0, L/2]$ を Chebyshev 点（$N = 64$）でサンプリングし、 微分行列 $D$ を用いて微分を 行列演算 に置き換えます：

$$\frac{d^2 u}{dy^2} \longrightarrow D^2 \cdot \mathbf{u}$$

Chebyshev 点は端点付近に密集するため、境界層を高精度に捉えられます。 標準域 $[-1, 1]$ から物理域 $[0, L/2]$ へのスケーリングは

$$\frac{dy}{dx} = -\frac{L/2}{2} \quad \Rightarrow \quad D_\text{phys} = D_\text{std} \Big/ \frac{dy}{dx}$$
なぜ Chebyshev か？ 均等格子（有限差分）と比較して、同じ格子点数で指数的に高精度な微分近似が得られます。 FMI 均衡のような滑らかな関数に特に有効です。

4.2 Newton 継続法（Continuation method）

ベクトルポテンシャルの振幅 $a_0$ を小さな値から目標値まで 段階的に増加させながら非線形方程式を解きます。

初期値：線形化 ODE の解析解で初期推定
↓
$a_0 = 0.01 \to a_{0,\text{target}}$ を 25 ステップで継続
↓
各ステップで scipy.optimize.root（LM 法）で求解
↓
前ステップの解を次ステップの初期値に再利用

4.3 未知数ベクトル

解ベクトル $\mathbf{u}$ は $2(N+1) + 1 = 131$ 次元： 

u = [ A[0], A[1], ..., A[N],          ← N+1 個（ベクトルポテンシャル）
      Φ[0], Φ[1], ..., Φ[N],          ← N+1 個（スカラーポテンシャル）
      L_half ]                          ← 1 個（ドメイン半幅、未知数）

ドメイン幅 $L_\text{half}$ も未知数として同時に決定します。 これが計算コストを下げながら自己一致解を得るための工夫です。

5. コード構造の詳細

5.1 chebyshev_diff_matrix(N)

標準 Chebyshev 微分行列 $D \in \mathbb{R}^{(N+1)\times(N+1)}$ と Chebyshev 点 $x_j = \cos(j\pi/N)$ を返します。 

def chebyshev_diff_matrix(N):
    x = np.cos(np.arange(N + 1) * np.pi / N)   # Chebyshev ノード
    D = np.zeros((N + 1, N + 1))
    p = np.ones(N + 1); p[0] = 2; p[N] = 2     # 端点の重み係数
    for i in range(N + 1):
        for j in range(N + 1):
            if i != j:
                D[i, j] = (-1)**(i+j) * p[i] / (p[j] * (x[i] - x[j]))
    # 対角成分（sum formula で厳密計算）
    D[0, 0]   = (1 + 2 * N**2) / 6
    D[N, N]   = -(1 + 2 * N**2) / 6
    for j in range(1, N):
        D[j, j] = -x[j] / (2 * (1 - x[j]**2))
    return D, x

5.2 residual(u, current_a0)

非線形連立方程式の残差ベクトルを返します。 root() がこれをゼロにするように解を探索します。 

def residual(u, current_a0):
    A, Phi   = u[:N+1], u[N+1:2*N+2]
    L_half   = np.abs(u[-1]) + 1e-6          # 正値を保証
    dy_dx    = -(L_half / 2.0)               # スケーリング係数
    D_phys   = D_std  / dy_dx               # 物理座標の 1 階微分行列
    D2_phys  = D2_std / dy_dx**2            # 物理座標の 2 階微分行列

    # Boltzmann 因子（数値オーバーフロー防止のため clip）
    arg_b = np.clip((γ_b/T_b) * (Φ - β_b * A), -100, 100)
    arg_p = np.clip((γ_p/T_p) * (Φ - β_p * A), -100, 100)

    # 支配 ODE の残差
    eq_A   = D2_phys @ A   - 2*(γ_b*β_b*sinh(arg_b) + γ_p*β_p*sinh(arg_p))
    eq_Phi = D2_phys @ Phi - 2*(γ_b    *sinh(arg_b) + γ_p    *sinh(arg_p))

    # 内部点 + 4 つの境界条件
    res[1:N]         = eq_A[1:N]            # ODE（内部）
    res[N+2:2N+1]    = eq_Phi[1:N]          # ODE（内部）
    res[0]           = A[0] - current_a0    # BC: A(0) = a0
    res[N+1]         = (D_phys @ Φ)[0]      # BC: dΦ/dy(0) = 0
    res[N]           = (D_phys @ A)[N]      # BC: dA/dy(L/2) = 0
    res[2N+1]        = (D_phys @ Φ)[N]     # BC: dΦ/dy(L/2) = 0
    return res

5.3 線形化による初期推定

$a_0 \to 0$ 極限では方程式が線形化され、解析的に固有値を求められます：

$$k^2 = -(C_{AA} + c_1 C_{A\Phi}), \quad L_\text{half} = \frac{\pi}{k}$$

ここで $C_{AA},\, C_{A\Phi},\, C_{\Phi\Phi}$ は各成分の密度 $\times$ 速度の係数です。

C_AA     = -2 * (γ_b²β_b²/T_b + γ_p²β_p²/T_p)
C_APhi   =  2 * (γ_b²β_b  /T_b + γ_p²β_p  /T_p)
C_PhiPhi =  2 * (γ_b²     /T_b + γ_p²     /T_p)

# 2x2 固有値問題を解く（phi_ratio = Φ/A の比）
D_q = b_q**2 - 4 * a_q * c_q
phi_ratio = (-b_q + sqrt(D_q)) / (2 * a_q)
k2 = -(C_AA + phi_ratio * C_APhi)
L_half_guess = π / sqrt(k2)

5.4 規格化

出力前に、プラズマ成分の最大密度 $\max(d_p)$ で全フィールドと密度を規格化します。 これにより異なる $a_0$ での比較が容易になります。

6. 出力・可視化

プロットは左右 2 パネルで構成されます：

パネル縦軸横軸線種
左：電磁場 $y\ [c/\Omega_p]$ $B_{0z},\, E_{0y}\ [mc\Omega_p/e]$ 実線 $B_{0z}$、破線 $E_{0y}$
右：見かけ密度 $y\ [c/\Omega_p]$ $d_\alpha^\pm / \max(d_p)$ 赤 = plasma、青 = beam

「見かけ密度」は $d_\alpha^\pm = \gamma_\alpha e^{\pm\xi_\alpha}$ で定義され、 $+$ が進行方向、$-$ が逆行方向の粒子密度に対応します。

結果は work/fig1_a0<value>.png に保存されます。 $y$ 方向は半ドメイン解を反転対称化（$A$：偶関数、$\Phi$：奇関数）して全周期を表示します。
